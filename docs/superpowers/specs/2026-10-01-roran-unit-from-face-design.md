# 顔グラを入力にしてロランのユニットに特徴を反映する（issue #23 の2番目）設計

作成: 2026-10-01

## 目的

issue #23（ロランのアセット修正）の2番目「顔グラを入力にして、ユニット（マップのドット絵）に特徴を反映する」。
1番目（ロランの顔グラを forge で描く、ブランチ `feat/roran-face`）は依頼者が手で直している途中なので、その完成を待たずに、
main にあるフリー素材の顔（`assets/images/roran-face.png`）を入力にして先に進める。

## 決めたこと

依頼者の判断:

- 顔から移す特徴は次の5つすべて
  - A. 髪の色（暗い青灰）
  - B. 髪の形（耳まで覆うぼさぼさの髪・目まで下りた前髪）
  - C. 肌の色（桃色寄り）
  - D. 目（大きく、少し縦長に）
  - E. 服（暗い上着・青緑の線・首元の赤紫）
- 色は `feat/roran-face` の `pixel-asset-forge/palette/master.json` を1字違わずそのまま取り込み、その色だけで描く。
  足りなければ、その時点で止めて依頼者に確認する
- 進め方は段階に分け、段階ごとに見せて止まる（下記「段階」）

前提（依頼者に示して異論なし）:

- シートの並び・コマ数は今のまま。ゲーム側の JSON（`assets/units/roran.json`）は変えない
- 持ち物（剣・盾）は変えない（issue #23 の3・4番目で扱う）
- 仕上がりの判断は依頼者がする。「一旦進めましょう」は次の段階へ進んでよいという意味で、合格ではない

範囲外:

- 顔グラ（`assets/images/roran-face.png`）の差し替え。1番目の作業で行う
- ほかのユニット（issue #23 の5番目）

## 入力: フリー素材の顔の読み

フリー素材の顔（128px）は、24px のドット絵を約 5.33 倍に拡大したもの。各升の中央の画素を取ると 24px に戻る。
ただし拡大のときにぼかされていて、升の中央の画素にも数階調のゆれがある。各成分の差が 14 以下の色を1色にまとめると 14 色になる。

- 構図: 画面の左を向いた斜めの顔
- 髪: `#2d2637`（最も暗く、輪郭を兼ねる）・`#3b334a`・`#474865`・`#63728b`（青灰の明るい色）。耳まで覆うぼさぼさの髪で、前髪は目の高さまで下りる
- 肌: 地 `#ddb6b6`、影 `#c08d96`・`#a97a86`・`#9a667b`。桃色寄り
- 目のあたり: y=11 の x=7 に `#e6ece1`、x=12 に `#d7dfd6`（どちらも淡い1px）。その上の y=9〜10 に暗い赤紫（`#583e51`・`#88576d`）。どの画素が瞳でどれが白目かは決めつけない
- 服: 暗い地に青緑 `#7398a6` と `#63728b` の線。首元（y=20〜21、x=10〜15）が赤紫（`#88576d`・`#a97a86`）

## 1. 色の対応（段階1）

24コマとも `# map:` の行が同じなので、`map` の行だけを書き換えて24コマの色を一括で置き換える。絵の文字は変えない。

| 文字 | 今 | 置き換え後 |
|---|---|---|
| `a` `b` `c`（肌） | `skin_hi` / `skin_base` / `skin_shadow` | `skin_rose_hi` / `skin_rose_base` / `skin_rose_shadow` |
| `e` `f` `g` `h`（髪） | `hair_hi` / `hair_base` / `hair_shadow` / `hair_dark` | `hair_slate_hi` / `hair_slate_base` / `hair_slate_shadow` / `hair_slate_dark` |
| `p` `q` `r`（服） | `cloth_hi` / `cloth_base` / `cloth_shadow` | `cloak_dark_hi` / `cloak_dark_base` / `cloak_dark_shadow` |
| `o`・金属・石・木 | そのまま | そのまま |

測ったこと（`probe_colors.py`）:

- 置き換え後の髪・服・首元の色は、`outline`・`grass_shadow`・`grass_base`・`leaf_shadow`・`dirt_shadow`・`floor_dark` のどれに対しても引っかからない
- **髪と服の色がほとんど同じ。** `hair_slate_base` と `cloak_dark_base` は ΔE 4.6、`hair_slate_dark` と `cloak_dark_shadow` は ΔE 2.9。
  元絵でも髪と上着は同じ色を使っている。髪と服が接するところには `outline` の1pxを挟む。段階1の後と段階5の後に `check_colors.py` で確かめ、
  引っかかった箇所は見せるときに依頼者に伝える
- `cloak_dark_hi` は青緑（`#6c8c9a`）なので、段階1では今の服の明るい面がそのまま青緑になる。元絵では青緑は線だけなので、段階1の見た目は途中の状態。模様は段階3で描く

## 2. 頭と服の描き方（段階2・3）

**段階2a: 髪の形**（`down_base` で3〜4案）

- 元絵から移すのは、耳まで覆う横の髪、目のすぐ上まで下りた前髪、ぎざぎざした外形
- 頭頂は今と同じ y=5 より上に出さない（背丈の規約）。ボリュームは横（左右1px程度）と外形の凹凸で出す
- 案ごとに前髪の長さと外形の凹凸の付け方を変える

**段階2b: 目**（2a で選んだ髪の上で3〜4案）

- 大きく、少し縦長に。今の輪郭色の1pxの点2つ（y=11）を、縦2pxを基本に、幅と色を変えた案を描く。色は `iris_slate`・`iris_slate_dark`・`eye_white`・`outline` から選ぶ
- 目の上端の行は4方向でそろえる
- 決まったら `types/unit/SPEC.md` の「顔」の規約（正面は1pxの点2つ、横顔は1pxの点1つ）を新しい目の形に書き直す

**段階3: 服の模様**（`down_base` で2〜3案）

- 暗い上着に青緑（`cloak_dark_hi`）の線、首元を赤紫（`skin_rose_deep`、`#8a5a68`）にする。案ごとに線を入れる場所（襟・前の合わせ・裾）を変える

**見せ方**（どの段階も同じ）

- 案を横に並べ、8倍の拡大と等倍を添える。左端に 24px に戻した元絵の顔を置く
- 1枚の画像にして Read で見せ、止まる

## 3. 残りの方向・アニメ・ゲームでの確認（段階4〜6）

**段階4: 残りの3方向の `base`**

- `up`・`left`・`right` に決まった髪・目・服を描く。横顔の目は1つで、正面の目に形を合わせる。背面には目がない
- `contact_sheet.py --columns 4` で4方向を並べ、等倍を添えて見せる

**段階5: アニメの20コマ**

- 頭と服の部分は `base` から写す（写すのは `.superpowers/` に置く使い捨ての道具。git に入れない）。
  剣が頭や服に重なるコマ（`breathe` と攻撃の2コマ × 4方向 = 12コマ）は手で直す
- `sheet.py sheets/roran.txt` のプレビュー（足元の赤い線・中心の線）で見せる
- `validate.py` と `check_colors.py` を通す

**段階6: ゲーム**

- `export.py sprites.json assets/images` で `roran-map.png` を書き出す。コマ数は変えないので JSON はそのまま
- `npm test` と `npm run build` を通し、CDP で戦闘画面を撮って見せる
- 最後に `contact_sheet.py` を更新する

## 追記: 攻撃のコマの振り方（2026-10-01）

段階5（アニメの20コマ）を見た依頼者の判断で、攻撃の `atk_hit` をこのブランチで描き直す。上の「持ち物（剣・盾）は変えない」の例外とする。
依頼者の考え: issue #23 の4番目は剣をカスタマイズするための入力を別のアセットにする作業であり、振り方の規約（45°の斜め）はここで直すのが適切。

依頼者の指摘:

- 正面・背面の `atk_hit` は、振り上げた後に剣を斜めにぶらしているように見える。真っすぐ前に振り下ろすようにしたい
- 背面では剣が体に隠れて見えなくなってよい
- 横向きの `atk_hit` の剣をもっと前に出したい。今の切っ先はコマの端から3px内側（左向き x=3、右向き x=28）で、32px のコマのまま前へ出せるのは2px程度

決めること（段階ごとに案を並べて依頼者が選ぶ）:

- **段階5b: 正面の `atk_hit`**（2〜3案）。拳を体の前の中央に下ろし、刃を体の前で真っすぐ下へ向ける。案ごとに刃の長さ（手前に向いて短く見える分）と拳の高さを変える
- **段階5c: 背面の `atk_hit`**（1〜2案）。拳を体の前へ下ろし、剣は体に隠れる。肩と腕の動きで振り下ろしたことを見せる
- **段階5d: 横向きの `atk_hit`**（2〜3案）。刃の傾きを今（縦2行につき横1px）より寝かせて前へ出し、切っ先をコマの端の輪郭の手前（左向き x=1、右向き x=30）まで出す。左右は別々に描く
- `atk_wind`（振り上げ）はそのまま
- 決まったら `types/unit/SPEC.md` の「攻撃は振り下ろし」の `atk_hit` の規約（正面・背面は45°、横向きは縦2行につき横1px、方向間の刃の長さを揃える）を書き直す

確認は段階5と同じ（`validate.py`・`check_colors.py`・`sheet.py` のプレビュー）。`sheet.py` の中心の `off` は、正面の `atk_hit` が `ok` に変わりうる。
