# ミストのマップ用ユニットを部品から作る（設計）

2026-11-06。依頼者との相談（brainstorming）の結果。

## 目的と理由

ミスト（味方・魔法役。`assets/units/mist.json`）のマップ用の絵は、今は仮のピンクの絵（`assets/images/mist-map.png`）で、
顔グラ（`assets/images/mist-face.png`）とも似ていない。ほかの味方3体と敵16体は部品から組み直し済みで、ミストが残っている。

ミストは、部品を 素体（芯: 頭・胴・脚）・髪・被り物・目・服・拳・武器 に分ける方式（`pixel-asset-forge/types/unit/SPEC.md`
「部品で組む規約」、2026-10-16 依頼者）で最初から作る、最初のユニットになる。

## 見た目（依頼者の言葉）

- ローブをまとっていて、基本は黒が基調
- 顔グラのような帽子をかぶり、杖を持っている
- ローブは足元まであり、歩いても足はほとんど見えない
- 攻撃は、杖を上に掲げるか、杖を前に振るかのどちらか（両方を組んで見比べ、依頼者が選ぶ）
- 「これだけは外したくない」点は、今の時点では無い（依頼者）

## Claude の推測として依頼者に示し、「違っているところは無い」と返ったもの

- 帽子は顔グラと同じ、紫のつば広のとんがり帽子に金の留め金。帽子の下から茶色の長いくせ毛がのぞく
- 体は女性の素体（イネスや女性の敵と同じ細い体）から作る
- ~~歩きは、足の代わりにローブの裾の揺れで見せる~~ → 下の「歩きの見せ方」で (a) に改めた
- 杖は刃の無い武器として扱う（`blade` を書かないので `tip_check` は掛からない）。ほかの確認は他のユニットと同じく通す
- 部品は 素体・髪・被り物（帽子）・目・服（ローブ）・拳・武器（杖）。「被り物は髪より大きく」（`head_cover_check`）も当てはまる
- 作り方はこれまでの敵と同じ: 部品を描き、`compose` で 24コマを組み、`unit_rules` を例外0件で通し、ゲームへ書き出す

## 歩きの見せ方（依頼者の判断、2026-11-06）

`still_check` は歩きのコマで、上半身と部品（服を含む）が `base` のままで、芯は脚（y=28〜30）と上げた足の上の輪郭（y=27）だけが
動いているかを確かめる（SPEC「アニメの規約」の `walk`）。裾を歩きのコマごとに揺らすとこれに落ちる。

依頼者は (a) を選んだ: **ローブの裾は歩きでも `base` のまま動かさず、裾の下からのぞく足先（芯の y=28〜30）だけで歩きを見せる。**
「いったんこれで」とのことなので、確認4の再生ページで歩きが地味すぎると依頼者が判断したら見直す。
見送った案: (b) 揺れる裾の下端を芯の脚の行に描く（服は服の部品に描く分け方から外れる）、(c) `still_check` の決まりを変える。

## 依頼者に見てもらう所（4回。依頼者が合意）

これまでの CP0〜CP4 の5回を、道具では判断できないことだけに絞った。道具で落ちたものは Claude が道具に従って直す
（`CLAUDE.md`「ドット絵の確認の道具」）。

1. **物の見え方**: 帽子・ローブ・杖・髪を、単品で向きごと（down・up・left・right）に描いたページで合わせる
2. **重なり順**: 向きごとの層を奥→手前に並べたページで合わせる（杖と体・拳、帽子のつばと髪、ローブと拳など）。合意した順が `checks/mist.json` の `orders` になる
3. **攻撃の動き**: 「掲げる」と「振る」の2案を組み、再生ページで並べて、依頼者が選ぶ
4. **完成品**: 道具を例外0件で通した全コマを、状態×4方向の再生ページで見せる。承認の後でゲームへ書き出してコミットする

見せ方はこれまでどおり Artifact のページ（スマホで見る）。赤枠の印を付けるときは印なしと対で並べる。
絵を変えたら、コミットや次の段階の前に見せる。

## 目標

- `pixel-asset-forge/compose/mist.json` と `checks/mist.json` を作り、全コマを単品の部品から組む
- `tools/unit_rules.py checks/mist.json` が例外0件（`exceptions: []`）で通り、`compose.py compose/mist.json --check` が通る
- ゲームの `assets/images/mist-map.png` を新しいシートに差し替え、ゲームで動く

## 目標にしないこと

- 顔グラ（`mist-face.png`）は変えない。顔グラの作業（`feat/roran-face`）は依頼者の判断で保留中
- 魔法の弾・光などの効果をユニットの絵に描かない。ゲームが弾を別に描く（`src/core/constants.ts` の `PROJECTILE_SPEED.magic`）
- ほかのユニットの絵や、既存の道具の判定を変えない（新しい道具が要ると分かったら、作る前に依頼者と相談する）
- `garum`（`frame=48`）は対象外

## 決まっていて、守ること

- 正典: `pixel-asset-forge/types/unit/SPEC.md`（特に「部品で組む規約」「色の決まり」「描く手順」）、`pixel-asset-forge/CLAUDE.md`、ルートの `CLAUDE.md`
- 部品は単品として完全に描く。重ねた後の後処理で補わない
- 腕は描かない（体＋拳）。袖の名残も残さない
- 拳は全向き・全コマで両手とも層を持つ。体の奥で武器を握る拳は影の肌の色だけで描く（`far_fist_check`）
- 拳の位置は down/up・left/right で左右反転にそろえる（攻撃のコマを除く。`hand_mirror`）。杖は left/right で位置をそろえる（攻撃も。`weapon_mirror`）
- 柄を包んで握る物は拳を手前に置く（杖もこれに当たると Claude は考える。重なり順の確認2で依頼者と合わせる）
- 承認された重なり順は Claude が勝手に変えない
- 新しい色は描く前に `probe_colors.py` で測り、用途の色は種類と説明を書いて `palette/uses/unit.json` に足す。
  杖は種類 `weapon`（武器の部品は輪郭と刃・武器の種類だけで塗る）、帽子は `headgear`、ローブは `cloth`
- 背丈（24〜26px）は芯で測る（`height_check`）。帽子は被り物の部品なので背丈に入らない
- ゲームのコマ数は `assets/units/mist.json` のまま（待機2・歩き4・攻撃3）。シートの並びはほかの味方（`sheets/roran.txt` など）にそろえる
- 攻撃の3コマをロランと同じ並び（wind・hit・base）にすると、ゲームは3コマ目で弾を出す（イネスの `windupOf` の仕組み）。
  弾の出る瞬間が自然かは、確認3の再生ページで依頼者に見てもらう（Claude の判断）

## 作る人に任せること

- 芯を `assets/part/body/enemy_female/` の複製から作るか、新しく女性の素体（`types/unit/base/female_*`）から作るか
- ローブを1つの服の部品にするか、上衣と裾に分けるか（Claude の判断: 歩きで裾を動かさないので1つでよい）
- 裾の高さ。足先が y=28〜30 でのぞくように、裾の下端をどこに置くか
- 杖の長さ・太さ・先端の飾りの形、片手で持つか（確認1で依頼者に見せて合わせる）
- 目の部品（既存の E0〜E5 を使うか、新しく描くか）
- 黒基調のローブ・紫の帽子・茶色の髪・金の留め金の具体的な色（既存の色見本を優先し、足すなら測ってから）
- 計画の分け方（タスクの切り方）
