# 尖った先端の描き方と確かめ方（D の前の保留 ①）設計

2026-10-22。依頼者と brainstorming で決めた（2026-10-20〜22）。PR イ（①②）の ① の部分。② 女性の体の線の確かめ方は別に設計する。

## 目的と経緯

forge の規約は「尖った先端を、輪郭に囲まれた1画素で表さない」（`pixel-asset-forge/types/item/SPEC.md`、2026-10-02）だけで、
何を先端とみなすか・先端をどう描くかが決まっていなかった（`pixel-asset-forge/ISSUES.md`「尖った先端をどう描くか」）。
そのため `tools/tip_check.py` は「刃・鏃の文字の画素で、上下左右がすべて輪郭のもの」を落とすだけで、
イネスの背面の攻撃の矢（`arrow_up_atk_wind`・`arrow_up_atk_draw`）が落ちたまま `unit_rules.py checks/ines.json` が終了 1 になっている。

依頼者と絵を見比べて、先端の描き方を決まりにした。目的は二つ:

1. ドット絵の生成全体で、刃・鏃の先端を同じ描き方にそろえる（依頼者「先端はこの描き方に統一しましょう」2026-10-21）
2. `tip_check.py` の判定をこの決まりに置き換え、D（敵16体の組み直し）の前に道具をそろえる

経緯の要点（判断はすべて依頼者）:

- 一時期のアイコンの剣（`0d3fd29` の前、切っ先が輪郭に囲まれた白1画素）は、尖っては見えるが「先端に玉が付いたよう」で不自然
- 依頼者の案「先端の白1画素を黒にし、先端だけを囲む黒を消す」をアイコンの剣に当てると非常によくなった。ただし短く見えるので、刃を1段伸ばした「案＋1段」を採る。イネスの背面の矢も同じく「案＋1段」を採る
- 縦の刃で、Claude が判断の共通点から3つの条件を出し、条件を満たす形を全部描いた（中身1〜7画素、22通り）。中身4画素以下は全部自然。5画素以上は不自然だが、先端でなく刃が太すぎるため
- 条件を満たしても、外形が刃の幅に届いた後に刃の色が細いまま続く形は全部不自然（条件4にした）
- 斜め（45°）は Claude の見立て「縦と横の線で切った形」で中身1〜4画素を全部描いた（10通り）。全部、先端として自然（4-3 は「刃としては変」だが先端としては問題なしと依頼者が撤回）
- 剣の刃は、つり合いから中身2画素が好ましい（依頼者。今のロランのユニットの剣は2画素）

## 決まり

言葉の定義:

- **刃の色**: 刃・鏃の文字（`checks/<ユニット>.json` の `blade`）の画素。**色でなく文字で見分ける**（2026-10-22 依頼者
  「色が同じでも、生成用テキストで刃かどうかを区別できるようにすればよい」）。item のアイコンも、刃・鏃に専用の文字を割り当て、
  どの文字が刃・鏃かを設定に書く（ユニットの `blade` と同じ考え方。書く場所は作る人に任せる）
- **黒**: 輪郭（`outline`）の画素
- **中身の幅**: 刃の本体（先端でない所）の1行あたりの刃の色の画素数。斜めの刃も、横の1行に並ぶ刃の色の画素数で数える
- **外形**: 刃の色と、それを囲む黒を合わせた形

### 縦・横の刃と鏃（横は縦を90°回したものとして読む）

1. 外形は、先端へ向かって1行につき左右1pxずつ細くなる（2px 跳ばない。外形が刃の幅に届くまで同じ幅の行を続けない）
2. 刃の色を、できるだけ細く（中身が奇数幅なら1画素、偶数幅なら2画素）して先端まで届かせる
3. 刃の色より先の黒は、1画素の厚み（一番先の行は黒だけで、その次の行に刃の色の先端がある）
4. 外形が刃の幅いっぱいに届いた後は、刃の色も毎行広げる（細い刃の色だけが何行も続かない）

（Claude の判断）外形も刃の色も、刃の中心線について左右対称に置く。依頼者が見て自然と判断した縦の形はすべて対称で、
片側に寄せた形（例: `.ooo.` / `ojooo` / `oijko`）は一度も見せていないため。対称でない先端は落とし、数えた後の一覧で依頼者に見せる。

例（`o` 黒、`i j k` 刃の色。上が先端）:

```
中身1      中身2      中身3（2通り）          中身4（2通り）
 .o.       .oo.      ..o..    .ooo.          ..oo..    .oooo.
 ojo       oijo      .ojo.    oojoo          .oijo.    ooijoo
 ojo       oijo      oijko    oijko          oijjko    oijjko
```

中身1はイネスの横向きの矢、中身2は今のロランのユニットの剣（「切っ先は平らな蓋」）と同じ形で、どちらも今のまま決まりに合う。

### 斜め（45°）の刃と鏃

5. 刃の色を縦の線と横の線で切り、刃の色の周りに黒を1画素の厚みで回し（上下左右で接する所）、2つの切り口が出会う角の1画素も黒で埋める。切る位置はどこでもよい

例（右上向き。`#` が角を埋めた黒）:

```
中身1        中身3（真ん中で切る＝剣のアイコンの案＋1段）
 ..o#        ..oo#
 .ojo        .oijo
 ojo.        oijko
```

縦の線だけで切った形・横の線だけで切った形も含む（中身 n なら n 通り）。

### 当てはめる範囲

- 刃・鏃の先端だけ。弓の端・鍔の端・斜めの矢や弦の1画素・足先など、刃の文字でない先端は見ない（2026-10-16 依頼者の判断を保つ）
- 中身4画素まで。5画素以上は刃として太すぎるので、この決まりの外（判定はせず、そういう刃があれば報告する）
- 今の規約「尖った先端を、輪郭に囲まれた1画素で表さない」は、この決まりに置き換える（A が玉に見えたのは決まりの1と5に反するため、と Claude は見ている）

## 道具: `tip_check.py` の判定を置き換える

- 刃の文字の画素のまとまりごとに先端を見つけ、向き（縦・横・斜め45°）を決めて、決まり1〜5に合うかを確かめる。合わない先端を、部品のファイル名と画素の位置で出す（今の出力の形に合わせる）
- 部品ごとの形で見る（2026-10-17 依頼者の判断。組んだコマで隠れて細く見えるのは見ない）
- item のアイコン（剣・弓の矢）も同じ判定にかけられるようにする（今は `checks/` の部品だけを見ている）
  - 弓のアイコン（`assets/item/bow.txt`）は、弦と鏃が同じ文字 `j`（`stone_base`）なので、鏃に専用の文字を割り当てる
    （`# map:` に鏃の `stone_hi`・`stone_base`・`stone_shadow` 用の文字を足し、鏃の画素だけ文字を付け替える。色と画素は変えない）。
    剣のアイコンは `stone_*` を刃にしか使っていないので、今の `i j k` をそのまま刃の文字として設定に書く
  - （Claude の判断）弓の鏃のように、刃の色の幅が一定でない形（軸より太い三角形の鏃）は、先端のまわりだけを決まりで見る。
    斜めなら決まり5（縦と横の切り口・黒1画素の厚み・角の黒）で、本体の中身の幅は使わない。「中身4画素まで」は、刃の色の一番広い行で数える
- 45° 以外の斜め・中身5画素以上は、落とさずに「対象外」として件数と場所を出す
- **作ったら、まず今ある絵の全部にかけて、落ちる数を数える**（forge の CLAUDE.md「新しい機械チェックを思いついたら、まず偽陽性を数える」）。
  対象: ロラン・イネス・ガウの部品（`checks/*.json`）、item のアイコン。敵（`assets/unit/<敵>/`）はかけない（Claude の判断: 部品に分かれておらず刃の文字も決まっていないうえ、鎧に `stone_*` を使う敵があり、色で拾うと意味のない件数になる。D で部品と `checks/<敵>.json` を作るときにかける）。
  落ちた絵は一覧のページで依頼者に見せ、1件ずつ「絵を直す」か「判定を直す」かを決めてもらう。**例外（exceptions）は作らない**
  - Claude の見込み: 弓のアイコンの鏃（`assets/item/bow.txt`）は角 `(14,1)` を埋めていないので落ちる。ガウの短剣（上の黒3画素が刃の色2画素の片側に寄る）も決まり1に合わない見込み。ロランの横向きの攻撃の剣（`sword_right_atk_hit` など、斜めの刃の角を埋めていない）も落ちる見込み。どれも数えた後に依頼者が決める
- テストは `tests/fixtures/` に固定した絵で書く（現役のアセットを読まない。`tests/test_no_live_assets.py`）。決まり1〜5のそれぞれについて、合う形と合わない形の両方を置く。上の例の形と、今回不自然と判断された次の形を使う（上が先端。どれも縦の刃）

  ```
  中身3「案」  B2        B2'       B3'       溝1行（中身3）
  .ooo.       .ooo.     ..o..     ..o..     ..o..
  oijko       .ojo.     .ooo.     .ooo.     .ojo.
  oijko       oijko     .ojo.     oojoo     oojoo
                        oijko     oijko     oijko
  ```

  斜めでは A（一時期のアイコンの剣、`git show 0d3fd29^:pixel-asset-forge/assets/item/sword.txt` の上の4行）を合わない形に使う
