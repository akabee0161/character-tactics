# D 敵の組み直し 設計

2026-10-27 依頼者と合意。D は、ユニットを「体＋拳」の方針で部品から組み直す作業の4番目
（2026-10-10 に決めた順 A ロラン → B イネス → C ガウ → D 敵）。
パスは、断りが無ければ `pixel-asset-forge/` からの相対。

## 目的と理由

敵16体（`assets/unit/` の `axe-*`・`dagger-*`・`spear-*`）を、ロラン・イネス・ガウと同じく、
完全な単品の部品から `compose/<敵>.json` で組む形に作り直す。

- 今の敵は古い生成スクリプト（`gen/enemy/` の `mkparts.py`・`mkframes.py`・`mkweapons.py`）が、
  腕・袖つきの体に部品を重ねて作っている。依頼者の方針（2026-10-11）は 体＋拳（＋武器）だけで、腕の部品も袖の名残も作らない
- 敵には `checks/<敵>.json` が無く、`tools/unit_rules.py` の方針の確認が掛かっていない
- `gen/enemy/` の出力はコミット済みのコマと合わない（ISSUES の2行）。作り直せない作り方を残さない

成功: 16体すべてが `compose.py --check` で部品から再現でき、`unit_rules.py checks/<敵>.json` が例外0件で通り、
依頼者が静止と動きの絵を承認している。

## やらないこと

- ゲーム（character-tactics）への組み込み。敵は今もゲームから使われていない。D の後に依頼者に聞く
- 頭身を変える（2026-10-27 依頼者「いいえ」）
- 素体に顔を描く（素体には顔を描かない決まり。down と up は目の部品で見分ける）
- 敵の数・頭・目・服・色の組み合わせを変える（今の16体の組み合わせのまま作り直す）
- ロラン・イネス・ガウの芯（`assets/part/body/<unit>/core_*`）を新しい素体に合わせて直す

## 進め方: 3回に分ける（依頼者の判断）

| 回 | 中身 | 敵 |
|---|---|---|
| 1 | 素体の見直し ＋ 頭・髪・目・服の部品の描き直し ＋ 短剣の敵 | `dagger-bandit`・`dagger-knight`・`dagger-horn`・`dagger-thug`（4体とも男性） |
| 2 | 斧の敵 | `axe-bandit`・`axe-horn`（男性）、`axe-bandit-{a,b,c}-f`・`axe-horn-{b,c}-f`（女性）の7体 |
| 3 | 槍の敵 ＋ 後始末 | `spear-knight`・`spear-thug`（男性）、`spear-thug-{a,b,c}-f`（女性）の5体 |

回ごとに 設計（この設計書の該当の節で足りなければ、その回の初めに追記の設計を書く）→ 計画 → 実装 → PR。
PR・push・マージは依頼者の指示があったときだけ。1回目が終わったら、2回目の前に依頼者に見せて止まる。

この設計書は1回目を作れる詳しさで書く。2回目・3回目は決まっていることだけを書き、その回の計画の前に足りない所を依頼者と決める。

## 1回目

### 1-1. 素体（`types/unit/base/{male,female}_{down,up,left,right}.txt`）

素体は新しいユニットを複製して作る土台。今の素体は拳を含んでいて、「拳は別の部品」の決まりに合わない。

- **頭を地肌の形にする（案 H1、依頼者「一度進めてみる」）。** 頭のてっぺんと横を 1px ずつ削る（髪1画素ぶんの厚み）。
  頭は y=5〜10 だけを置き換え、顔の下半分と首（y=11〜14）は今のまま。女性の頭は男性と同じ。
  案の画素は Claude の scratchpad の `head_drafts.py`（`d1/*_H1.txt`）にあり、ページ https://claude.ai/artifact/PnYJNMx8iRQQ7S28PEm9gw で見せた。
  髪の部品の外形（てっぺん y=5）は変えないので、髪を載せた背丈は変わらない。素体だけの背丈は1px 低くなる（24〜26px の範囲内）
- **拳を外す。** 拳が重なっていた所の胴・脚は、単品として完全になるように描き足す
- **胴をまっすぐな筒にする（Claude の判断。builder check の指摘）。** 男性の素体の `down`・`up` は肩に段がある（y=15 が x=11〜20、y=16 が x=9〜22、y=17 から下が x=10〜21）。
  ロランとガウの芯の胴はまっすぐな筒（y=15 から x=10〜21）で、使い回すガウの短剣と拳もこの体の位置に合わせて描かれている。
  `body_check.py` の「はみ出し」も「胴はまっすぐな筒」が前提で、肩の段は袖の名残と同じに落ちる（H1 の男性の素体に掛けると `down`・`up` の (9,16)・(22,16) が落ちた）。
  そこで素体の胴を、ガウの芯と同じ筒の外形にそろえる。あわせて `body_check.py` の頭・胴・脚の中心と輪郭の切れ目も通す（拳を外した後に測る）。
  女性の素体（肩が広く腰がくびれる。`--no-protrusion` を掛ける体）は胴の外形を変えない
- 「一度進めてみる」なので、拳を外した素体と、髪・被り物を載せた絵で、依頼者にもう一度見せて承認を得る。H1 が合わなければ素体の形をここで決め直す。
  **このときの被り物は、描き直す前の今の部品をそのまま H1 に重ねる**（描き直す前に見え方を決めるため。builder check の指摘）。
  今の bandana・horn は y=9 までしか覆わず、y=10 の顔の横は素体の肌なので、H1 では被り物の下の顔が左右 1px ずつ細く見える。
  被り物を広げるか、細いのを受け入れるかは、この絵を見て依頼者が決める。決まってから 1-3 で部品を描き直す
- 素体の PNG（`types/unit/base/*.png`・`*_x8.png`）はコミットされているので、`tools/render.py` で書き出し直す
- ISSUES の「素体は『一旦これで良い』の暫定」の行: ① を削除（2026-10-27 依頼者）。② は H1、③ は拳を外すことで片付く。頭身は変えないと決めた。
  行に残る物が無くなれば行ごと消す。「男性の素体の left で、奥の手が 1px 幅」の行も、素体から拳が無くなるので片付けてよいかを、そのとき確かめて消す

### 1-2. 部品の分け方

SPEC「部品で組む規約」の分け方（素体・髪・被り物・拳・武器）に **目** と **服** を足す（依頼者の判断）。
目（`assets/part/eye/E0`〜`E5`）と服（`assets/part/cloth/belt`・`tatter` と女性用の `*_female`）は、今も別の部品で複数の敵が使い回している。

敵の部品:

| 部品 | 置き場 | 1回目で使う物 |
|---|---|---|
| 芯（素体の複製） | `assets/part/body/enemy_male/`・`enemy_female/`（名前は Claude の判断、計画で変えてよい） | 男性 |
| 目 | `assets/part/eye/<名前>/` | E0・E2・E5 |
| 服 | `assets/part/cloth/<名前>/` | belt・tatter |
| 被り物・髪 | `assets/part/head/<名前>/`・`assets/part/hair/<名前>/` | bandana・full・horn・bare |
| 武器・拳 | ガウの物を使い回す（1-4） | 短剣・短剣の拳・空き手の拳 |

**芯は素体の複製から作る**（2026-10-24 依頼者。古い敵の絵や `gen/enemy/` から腕を消して作らない）。
状態（`base`・`idle2`・`walk_a`・`walk_b`・`atk_wind`・`atk_hit`）ごとの芯の作り方（歩きの脚、待機2・攻撃で体が変わるか）は、
ガウの芯（`assets/part/body/gau/core_*`）が `base` からどう変わっているかに合わせる（Claude の判断。ガウが今の手本で、短剣の拳はガウの体の位置に合わせて描かれている）。

### 1-3. 頭・髪・目・服の部品を描き直す

頭を H1 にすると、今の部品は新しい頭に合わなくなる（今の部品は、頭にかぶせて見える所だけを、髪込みの頭の外形に合わせて描いてある）。
「部品は単品として完全に描く」に従い、新しい頭に合わせて **単品として完全に** 描き直す（体に隠れる所も描く）。

- 1回目で描き直すのは、短剣の4体が使う物（被り物 bandana・full・horn・bare、目 E0・E2・E5、服 belt・tatter の男性用）。
  女性の髪（A・B・C）と女性用の服は2回目で描き直す
- 形は今の部品の見た目を引き継ぐ（色・形の案を新しく振らない）
- SPEC の描く手順どおり、部品だけを向きごとに描いた絵で先に見せる。前と後を並べる

### 1-4. 短剣の敵4体

- ガウの短剣（`assets/part/equip/dagger/dagger_<dir>_<状態>`）と拳（`assets/part/fist/gau/dagger_hand_*`・`free_hand_*`）を **そのまま使い回す**（依頼者の判断）。
  4体の武器と拳の動きは画素までガウと同じで、違いは頭・目・服・色だけ
- 重なり順は、武器と拳についてはガウの承認済みの順（`checks/gau.json` の `orders`）。
  被り物・髪・目・服と芯の順は、今の敵の重ね方（`gen/enemy/mkframes.py` の「目 → 服 → 長い髪 → 頭」、長い髪の背中側は体の後ろ）を引き継ぐ
- 拳の部品の色（`skin_rose_*`）は、今の敵の肌の色（`mkframes.py` の `MAPC` で `skin_rose_*`）と同じ
- 組み立て: `compose/<敵>.json` で `assets/unit/<敵>/` のコマを組む。色替えは今どおり `enemy/<敵>.json` のレシピと `tools/enemy_build.py`（服の色・`recolor`）
- `checks/<敵>.json` を足し、`unit_rules.py` を例外0件で通す。ガウの `checks/gau.json` を元にする

### 1-5. 見せ方と承認

依頼者と決めた進め方どおり（絵を直したら前と後を並べ、静止と動きで見せて承認を得てからコミットする。絵は Artifact のページ）。順番:

1. 素体（拳を外した H1・胴の筒。前と後。今の被り物を重ねた絵も）
2. 部品（単品を向きごとに。前と後）
3. 層の重なり（奥→手前に並べた絵）
4. 組んだコマ（静止と動き。今の敵と並べる。`tools/anim_compare.py` か `tools/enemy_gallery.py`）

## 2回目・3回目で決まっていること

- 斧・槍の形と持ち方は、2026-10-07 に合意した見え方（SPEC「武器を描くときの決まり（斧・槍の敵で合意）」）を引き継ぐ。腕と袖だけを消し、拳は浮かせる
- 女性は体が細いので、拳と武器の位置は男女別の部品にする（今の `mkweapons.py` も `FEMALE_SHIFT` で女性だけずらしている）
- 今の敵で承認されている重なり順（長い髪の陰に入る物を含む）は変えない
- 武器（斧・槍）は今は部品が無い（`mkweapons.py` の中で描いている）。部品として `assets/part/equip/axe/`・`spear/` に描く（置き場は Claude の判断）

## 道具

- 新しい機械チェックは、既存アセット全件にかけて偽陽性を数えてから決める（依頼者と決めた進め方）
- `weapon_check.py` の「手の輪郭」は、組み直した絵にかけて偽陽性を数えてから直し方を決める（ISSUES の「敵を 体 + 拳 の方針で組み直す」の行）
- 道具が正しい絵を落としたら、例外を足さずに道具の判定を直す
- `tip_check.py` を敵にかけないのは 2026-10-22 の設計（`2026-10-22-tip-drawing-rule-design.md`）の決定のまま
- `body_check.py` の「はみ出し」をやめる（`PROTRUSION_BODIES` を `()`）のは、ISSUES の行どおり3回目の最後（最後の敵が `unit_rules.py` を通ったら）

## 後始末（3回目の最後）

- `gen/enemy/` の3本（`mkparts.py`・`mkframes.py`・`mkweapons.py`）と、それだけが使う物を消す（依頼者の判断）
- ISSUES の「敵の生成スクリプトの出力が、コミット済みのコマと違う」「短剣の敵4体のコマを、生成スクリプトから作り直せない」「敵を 体 + 拳 の方針で組み直す」の行を消す
- README・CLAUDE.md の `gen/enemy/` の記述を直し、`tools/contact_sheet.py` を更新する
