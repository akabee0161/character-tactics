# 出撃を選ぶ 設計

2026-11-16 に依頼者と合意した内容です。「（Claude の判断）」と書いたものは、依頼者が決めていない点を Claude が決めたものです。

テストプレイの直し（6 工程）の工程 3「出撃と配置を選ぶ画面」。工程 1 は `2026-11-15-counter-allies-design.md`、工程 2 は `2026-11-15-show-strength-design.md`。

## 呼び方

工程 2 で「札」と呼んだもの（仲間・敵・レベルアップの能力を出す重ねる絵）を、これから「カード」と呼ぶ（依頼者の指定）。ゲームの画面の文字に「札」は出ていない。正典（README）の言い換えはこの工程で行う。ログ（工程 2 の設計書・計画・台帳）は直さない。コードの名前（`StatCard`・`stat-card.ts` など）はもともと card なので変えない。テストの説明文の「札」は、触るファイルだけ直す（Claude の判断）。

## 目的と背景

依頼者はテストプレイで、敵に合わせて誰を前に出し、誰を後ろに下げるかを決めたかった。ところが、敵の能力が分からなかったので決められなかった。

- 敵の能力は工程 2 で見られるようにした（配置の場面でマップ上の敵を押すとカード、ステージ選択の「敵を 見る」）。配置の操作（黄色い線より下へドラッグ）は今のままでよい
- 残っているのは **出撃する仲間を選べないこと**。工程 1 で仲間を 15 人にしたが、場に出るのは 8 人まで。今は加わった順などで 8 人が自動で決まり、残りは出撃しない。ステージ 6 以降で起きる

## 目標

1. 配置の場面で、出撃する仲間を選べるようにする（依頼者が A を選んだ。敵の位置とカードを見ながら決められる）
2. 選んだ仲間を、挑み直しと次のステージへ引き継ぐ
3. 工程 2 で出なくなったレベルアップのセリフを、レベルアップのカードの中に出す
4. 工程 1・2 で先送りした指摘のうち、この工程の近くのもの（村の加入の判定、M3、M7）を直す

## 目標にしないこと

- 配置の操作を変えること（今のドラッグのまま）
- 戦闘中に出撃を入れ替えること
- 工程 2 の軽微な指摘 M4（古いセーブのテスト）・M5（称号の読まれない値）は工程 4 に回す。M6（レベルアップのカードが出た直後の 1 タップで閉じる）は今のまま（依頼者の判断）
- 結果の画面の「上がった能力」は、村でもらった能力を含めたまま（依頼者の判断。変えない）
- `npm run balance` のボットの出撃の決め方を変えること（ボットのセーブには選んだ記録が無いので、今と同じ自動の 8 人になる）

## してはいけないこと

- 倒れたら負けになる仲間（ステージの `defeat` の `unitLost` の `defIds`。今はロラン、1 ステージではミストも）を出撃から外せること
- 9 人以上を場に出すこと
- 出撃を選び直したことで、加入の記録・レベル・村のごほうびの記録が変わること

## 決めたこと

### 配置の場面のボタン

- 下パネルの上段（`MESSAGE_BAR`）を、出撃を選べるときだけ 2 つに分ける。左が「出撃を 選ぶ」、右が「始める」（見本の形）
- 出撃を選べるのは、そのステージの出撃の候補（そのステージで場に出られる仲間の全員）が 8 人を超えるときだけ（Claude の判断）。8 人以下のときは今のまま上段の全体が「始める」

### 出撃の一覧

- 「出撃を 選ぶ」を押すと、出撃の候補の一覧が重なる。重ねている間は、下の画面に入力が届かない（工程 2 の重ねる仕組みと同じ）
- 見出しは「出撃する 仲間」、右に「n / 8」。説明の 1 行「押すと 入れる・外す。「強さ」で カード」
- 枠は 3 列で 15 人まで。並びは出撃の候補の並び（ステージ選択の仲間一覧と同じ順）。各枠に顔・名前・レベル・役割。出撃している枠は金色の縁と「出撃」、外せない枠は「外せない」
- 枠を押すと、入れる・外すが切り替わる（案 1）
  - 外せない仲間を押したら、外さずに「（名前）は 倒れたら 負けなので 外せない」と出す
  - 8 人のときに出撃していない仲間を押したら、入れずに「8 人まで。先に 誰かを 外す」と出す
- 枠の右下の「強さ」を押すと、その仲間のカード（工程 2 の `cardFromUnit` か `allyCardFromSave` の今の値）が開く。カードを閉じると一覧に戻る
- 下の「決める」で閉じる。0 人にはならない（外せない仲間が必ず 1 人以上いる。いないステージは無いが、念のため 1 人以上でないと「決める」を押せないようにする。Claude の判断）
- 一覧の外を押したときは何もしない（誤って閉じると選び直しが消えるため。Claude の判断）。閉じるのは「決める」だけ

### 説得する仲間

- 説得する役の仲間（`persuasions` の `persuader`。今は s7 のミスト、s9 のガウ）は、外せない仲間にしない。一覧に印も出さない（依頼者の判断）。外して始めた回は説得ができず、相手は敵のまま。もう一度そのステージを遊べば説得できる
- 説得できることには、会話などで気付かせる（依頼者の判断）。今の導入の会話にすでに手がかりがある（s7 ミスト「塔に いる 魔法使いの 女の子……昔の 友だちかも しれません」、s9 ガウ「野営地に 昔 世話に なった やつが いるらしい」）ので、この工程では会話を変えない（Claude の判断）

### 「決める」の後

- 選んだ一覧で戦いの状態を作り直す（作り方 1）
- 残した仲間は、置いた場所のまま。外した仲間はマップから消える。入れた仲間は、空いている開始位置（`startPositions` と同じ決め方で、残した仲間の位置と重ならないところ）に出る
- 下の段の顔の枠の並びは、出撃の一覧の並び（Claude の判断。作り直した状態の仲間の並び）
- 作り直しは配置の場面（時間 0）なので、敵の見た目は変わらない。乱数の種はそのステージの最初の種を使い直す（Claude の判断）

### 誰が最初に選ばれているか（引き継ぎ、案 イ）

ステージの配置の場面に入ったときの出撃は、次の順で 8 人まで埋める。

1. 外せない仲間
2. そのステージの開始時に加わる仲間（`joins`）。最初から入れておくが、一覧で外せる（Claude の判断）
3. セーブに残った前回の出撃（並びのまま）のうち、このステージの候補にいる仲間
4. 今の自動の順（開始時の加入 → `roster` → 加わった順）

重複は除く。8 人を超える分は後ろから外れる（つまり前回の出撃の後ろの方から。Claude の判断）。セーブに前回の出撃が無いとき（最初・ボット）は、今の自動の 8 人と同じになる。

- 前回の出撃は、「始める」を押したときにセーブへ書く（今もこの時点でセーブしているので、そこに足す）。クリアしたかどうかに関係なく残す（Claude の判断。次に何を選んだかの記録で、進行ではないため）
- 挑み直し（負けて「もう一度」）は、同じ出撃と同じ置き場所で始める。置き場所はセーブに書かず、画面の側で覚えておく（Claude の判断。同じステージを続けて遊ぶ間だけ要る）
- 出撃を選ぶかどうかは、この選び方を 1 つの純粋な関数にして、テストを書く

### 戦いの状態を作る処理

- `createBattleState` に、出撃する仲間の一覧（任意）を渡せるようにする。渡さないときは今の自動の決め方
- 渡した一覧に、候補にいない仲間・9 人目以降があっても場に出さない（呼ぶ側の誤りを場に出さない）
- 開始時の加入（`joins`）の記録は、出撃から外しても必ず残す（今の「場に出なかった加入者」と同じ扱い）

### 村の加入の判定（工程 1 の先送り）

今は、村で加わる仲間が加入済みかを「そのステージで加わったか、場にいるか」だけで見ている。出撃を選べるようになると、加入済みの ally07 を外したまま s4 の村へ行くと、加入の会話がもう一度起き、レベルが加わったときの値に戻る。セーブの `members`（加わった仲間）も見て、加入済みなら「すでに仲間」の扱いにする。テストを書く。

### レベルアップのセリフ

- レベルアップのカードの中に、その仲間のレベルアップのセリフ（`levelup:<id>`、今は 15 行）を出す（依頼者の判断）。置き場所は顔と名前の近く。行が無い仲間は出さない
- 戦闘中のセリフ欄には出さない（今のまま）

### 先送りの指摘

- **M3**: 敵の一覧は 6 行まで。7 種類以上の敵が出るステージを足すと、7 行目が「閉じる」と重なる。行の数に上限を決め、それを超えるステージは読み込みの検証で止める、または一覧が収まるように行の高さを変える（どちらにするかは作る人に任せる。今のステージで最も多い種類の数をテストで確かめる形が、`stage-limits` の既存のテストにある）
- **M7**: 別の指でステージ一覧をドラッグしている間にカード・一覧を開くと、その下で一覧が動き続ける。重ねる物を開いたら、進行中のドラッグを終える。新しく足す出撃の一覧でも同じことが起きないようにする

### 文書

- README の「強さを見せる（札）」の節と、操作の表の「札」を「カード」に言い換える
- README に出撃を選ぶ操作を書く。「今は出撃を選ぶ画面が無く」の記述を直す
- CLAUDE.md は変えない（手順・規約の変更が無い）

## 確かめ方

- ユニットテスト（純ロジック）: 最初に選ばれる出撃（外せない仲間・開始時の加入・前回の出撃・自動の順・8 人の上限・候補にいない仲間を除く）。一覧の入れる・外すの判定（外せない・8 人）。`createBattleState` に一覧を渡したときの場の仲間と加入の記録。村の加入の判定でセーブの `members` を見ること。セーブの前回の出撃の読み書き（壊れた値・知らない ID を捨てる）。M3 の上限
- ブラウザ（README の CDP 手順）: s6 以降の配置の場面で、ボタンが 2 つに分かれる。一覧で入れる・外す・外せない・8 人の案内。「強さ」でカードが開き、閉じると一覧に戻る。「決める」の後、残した仲間の位置が変わらず、入れた仲間が開始位置に出る。次のステージで前回の出撃が引き継がれる。負けて挑み直すと同じ出撃・置き場所。s1〜s5 では上段が「始める」だけ。レベルアップのカードにセリフが出る
- `npm test`・`npm run build`・`npm run balance`（勝率が今と変わらないこと。ボットの出撃は変わらない）
