# 剣・弓のアイコン（item 型）設計（issue #23 の3番目）

作成: 2026-10-02

## 目的

issue #23（ロランのアセット修正）の3番目「剣・弓のアイコンを生成する（item 型）」。
16px のドット絵の剣と弓を forge で描く。役割アイコン（16px で描き 32px で表示）と、4番目でユニットの持ち物へ反映するときの元絵を兼ねる。
あわせて、無かった item 型の規約（`types/item/SPEC.md`）を作る（依頼者の方針: 基本的にはルールを作る。進めながら考える）。

## 決めたこと（依頼者の判断）

- 大きさ: アイコンはユニットの剣と別のアセットとして、16px いっぱいに大きく描く。ユニットの画素の大きさ（刃2px幅）には合わせない。
  4番目は画素の写しではなく、形と色の特徴を揃える反映にする
- 向き: 剣は右上に切っ先を向けた45°の斜め置き。弓も矢も45°の斜め置きで、矢は弓の真ん中を通す
- 見た目の手本: 今の `assets/images/role-tate.png`（剣）と `role-yumi.png`（弓）の構図。剣は茶の鍔と柄頭の赤い宝石。弓は左下の羽根から右上の鏃へ矢が通る。
  手本は構図だけで、色と画素は写さない（32px で、色が master パレット外のため）
- 色は master パレットの既存色だけを使い、足さない:
  刃・鏃・弦 `stone_*`、鍔・柄・弓本体 `wood_*`、剣の宝石 `roof_*`、矢の羽根 `water_*`、輪郭 `outline`
  （`feat/roran-face` と `master.json` がぶつからないようにするため。足りなければ止めて確認する）
- 範囲: forge でアセットを描いて `build/item/` に PNG を出すところまで。`sprites.json` への記載、ゲームの役割アイコンの差し替え（描画側の 32px 表示のレイアウト修正を含む）は含めない

## 作るもの

- `pixel-asset-forge/assets/item/sword.txt`・`bow.txt`（16×16、`bg: transparent`、`light: upper-left`、輪郭は `outline` を全周1px。既存の `chest.txt` と同じ）
- `pixel-asset-forge/types/item/SPEC.md`: 描いて測った数字（輪郭、色の段数、使う色、余白）を表にする。`reference/` に何を置くかは絵が決まってから決める
- 剣の規約（unit/SPEC.md の攻撃の規約: 柄頭→拳→鍔→刃を1本の軸に並べ、鍔は刃に直角）は、アイコンの剣にも適用して確かめる

## 進め方

1. 剣の案を3案描き、Read で見せて止まる。各案に 16px 等倍と 32px 表示（2倍）の縮小を添える
2. 選ばれた剣を仕上げ、同じ手順で弓を行う
3. 絵が決まった後で SPEC.md を書く
4. `tools/validate.py`・`tools/check_colors.py` を通し、`tools/render.py` で PNG を出す
5. 「一旦進めましょう」は次の段階へ進んでよいという意味で、合格ではない

## 触らないもの

パレット、`feat/roran-face`、ゲーム側のコード、`tools/`（触らないので unittest は不要）。push と PR は依頼者の指示があるまでしない。

ユニットの持ち物への反映（4番目）、ほかのユニット（5番目）。
