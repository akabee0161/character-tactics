# イネスを forge のユニットとして描き、弓を持たせる 設計（issue #23 の5番目）

作成: 2026-10-03

## 目的

issue #23（ロランのアセット修正）の5番目「ほかのユニット」。
イネスを forge のユニットとして描き、弓（forge の `assets/item/bow.txt`）をイネスの持ち物として上手く描けるかを試す。
あわせて、イネスの顔グラ（`assets/images/ines-face.png`）を入力にして、ユニットを顔に似せる（2番目でロランに行ったのと同じ作業）。

持ち物への反映は、4番目と同じく画素の写しではなく、形と色の特徴を揃える。

## 測った今のアセット（2026-10-03）

**`assets/images/ines-map.png`（128×384）** は forge で描いたものではない仮置きの絵。

- 色は5色（服 `#3faa6a`・髪 `#235e3a`・肌 `#f2d6b2`・目と脚 `#28242c`・弓 `#966a3e`）。輪郭なし
- 足元は y=27（規約の y=30 ではない）。外接矩形は x=10〜22・y=7〜27、背丈21px
- 弓は茶色の 2×8〜10px の棒。正面では画面右の手前（x=21〜22）、背面では画面左（x=8〜9）、横向きは顔の前。攻撃のコマは棒が動くだけ

**`assets/images/ines-face.png`（128px）** は 32px のドット絵を4倍にしたもの（4px おきに色の変わり目が出る。ロランの顔は 24px の約5.33倍だった）。
升の中央を取ると 32px に戻る（拡大のときにぼかされていて、各成分の差 14 以下をまとめても63色）。

- 頭を覆う桃紫は**髪ではなく大きなバンダナ**（依頼者の判断）。画面右で肩まで下がる部分（x=22〜31、y=19〜31）も含めてすべてバンダナとして描く。
  色は `#f492e4`・`#c059c0`・`#a946ab`・`#953ba0`・`#7f2783`・`#571562`
- 肌は暖かい桃橙（`#ffcb91`・`#f7b880`・`#e19366`・`#c16d50`）
- 太い暗い眉（y=10〜11）、目に白い点（`#f0e4df`、y=17〜18）
- 耳飾りはオレンジ（`#de6b2d`・`#f8832d`、x=4 と x=21 の y=20〜23）
- 服は黄色（最下段 y=31 の x=22〜26 に `#cbbd39` から暗くなる5画素。依頼者の見立て）
- 画面左下の青（x=4〜10、y=25〜30）は無視する（依頼者の判断。バンダナの桃紫とはつながっていない）

**ゲームの弓の攻撃:** `attack: "bow"` は攻撃のときに飛翔体を出し、相手を追いかける（矢は長さ12px・太さ2px の線 `#e8e2d0`）。
攻撃のアニメは3コマ・6fps で、最後のコマでクランプして 0.5 秒で待機に戻る。
**矢が出るのは攻撃を始めてから 0.33 秒後（`windupOf` = (3−1)/6）、3コマ目が出た瞬間。**

## 決めたこと（依頼者の判断）

- 描くのはイネスだけ。ガウ・ミストは描かない
- 顔から移す特徴は次のすべて:
  - A. バンダナの色（桃紫）
  - B. バンダナの形（頭を大きく覆い、画面右で肩まで垂れる）
  - C. 肌の色（暖かい桃橙）
  - D. 目と眉
  - E. 耳飾り（オレンジ）。**1〜2画素で表現できなければ省いてよい**
  - F. 服（黄色）
- 弓は左手で持つ。**待機では弓と矢を剣と盾のように別々に持たず、右手で弦にかけた矢を弓と交差させ、今にも引ける構えで待つ**（矢は引き絞らない）
- 弓の持ち方は、ほかの弓のユニットでも使えるパターンとして、`types/unit/SPEC.md` に文章と座標で書く。素体に弓を載せたテンプレートのグリッドは作らない
- **攻撃の3コマは `[atk_wind, atk_hit, atk_release]`**: 弓を前に上げて構える → 引き絞りきる（矢あり）→ 放った後（矢なし、右手が後ろへ抜ける）。
  3コマ目が出た瞬間に矢が出るので、放つ絵と矢の出る時刻が一致する。ロランは3コマ目に `base` を流用しているが、イネスは新しい絵を描く。
  描く絵は1方向7枚で28枚（ロランは24枚）。シートは 128×384 のままで、`ines.json` は変えない
- **女性形の素体 `types/unit/base/female_*` を作ってから描く**（`male_*` を複製して描く案・ロランの24コマを複製する案は採らない）。
  体つきは `male_*` から b. 肩幅を狭く、c. 腰にくびれ、d. 脚を細く（各3px → 2px）の3つを試す。背丈は26px のまま
- 色:
  - バンダナの4色をパレットに足す（依頼者 Yes）
  - 服の黄は既存の `metal_*` で描く（`metal_hi` は顔の `#cbbd39` に ΔE 19.1、`metal_shadow` は `#867f2f` に ΔE 16.7）。
    名前と見た目の食い違いが増えるが、命名の整理は `feat/roran-face` のマージ後に独立した作業として行う（5番目はこれを待たない）

## 範囲

**作るもの**

- 女性形の素体 `pixel-asset-forge/types/unit/base/female_{down,up,left,right}.txt`（`male_*` は変えない）
- イネスのコマ `pixel-asset-forge/assets/unit/ines/` の28枚: 方向ごとに `base`・`breathe`・`walk_a`・`walk_b`・`atk_wind`・`atk_hit`・`atk_release`
- シート定義 `pixel-asset-forge/sheets/ines.txt`（`sheets/roran.txt` と同じ並びで、攻撃の3コマ目だけ `*_atk_release`）
- `sprites.json` に `"sheets/ines.png": "ines-map.png"` を足し、`assets/images/ines-map.png` を書き出し直す

**変えないもの**

`assets/units/ines.json`、ゲームのコード、ほかのユニットと素体 `male_*`、役割アイコン（`role-yumi.png`）、
`feat/roran-face`、`pixel-asset-forge/tools/`（触らないので forge の unittest は不要）。push と PR は依頼者の指示があるまでしない。

**範囲外**

ガウ・ミスト、色の命名の整理、持ち物ごとのテンプレートのグリッド、`male_*` の暫定の点（ISSUES.md「素体は『一旦これで良い』の暫定」）の直し。

## 色

**足す色:** バンダナの4色。名前は素材ではなく色で `orchid_hi`・`orchid_base`・`orchid_shadow`・`orchid_dark`（`roof_*`・`water_*` と同じ付け方。命名の整理で付け替えずに済む）。

- 値は顔の色（`#f492e4`・`#c059c0`・`#7f2783`・`#571562` のあたり）を手がかりにし、描く前に `probe_colors.py` で
  肌（`skin_*`）・`outline`・服の黄（`metal_*`）・`grass_*`・`dirt_*`・`leaf_shadow`・`floor_dark` に対して測り、区別できる値に決める
- `palette/master.json` の末尾に足す（`hair_slate_*` から離し、`feat/roran-face` とのマージでぶつかりにくくする）

**既存の色で描くもの**

| 部分 | 色 |
|---|---|
| 肌 | `skin_hi` / `skin_base` / `skin_shadow`（顔の `#ffcb91` に `skin_base` が ΔE 9.5、`#e19366` に `skin_shadow` が ΔE 11.0） |
| 服の黄 | `metal_hi` / `metal_base` / `metal_shadow` |
| 耳飾り | `flame_deep` / `flame_base`（`#de6b2d` に `flame_deep` が ΔE 11.7） |
| 目 | `outline`（unit の顔の規約） |
| 弓・矢の軸 | `wood_*` |
| 弦・鏃 | `stone_*` |
| 矢羽根 | `water_*` |

弓・矢・弦・鏃・矢羽根の色は `types/item/SPEC.md` の素材ごとの割り当てに揃える。
**持ち物の部品には専用の文字を割り当てる**（`types/unit/SPEC.md`。服の黄と同じ `metal_*` を将来ほかの部品で使っても、`# map:` 行で片方だけ色を変えられるように、服の黄にも専用の文字を割り当てる）。

## 段階

段階ごとに Read で絵を見せて止まる。見せ方はどの段階も同じ:
案を横に並べ、8倍の拡大と草の上の等倍を添え、左端に 32px に戻したイネスの顔を置く。
案の差が小さいときは、どこが何画素違うかを書き添える。拡大の切り出しだけでなく、コマ全体の絵も見せる。
「一旦進めましょう」は次の段階へ進んでよいという意味で、合格ではない。

| 段階 | 内容 | 見せるもの |
|---|---|---|
| 0 | バンダナの4色を `probe_colors.py` で測り、パレットに足す | 色見本と測った表 |
| 1a | 女性形の素体 `female_down`（肩・くびれ・脚の置き方で2〜3案） | 案と `male_down` を並べる |
| 1b | 素体の残り3方向 | `contact_sheet.py --columns 4` |
| 2a | イネスの `down_base` のバンダナの形（垂れの長さと位置で3案ほど） | 案 |
| 2b | 目・眉・耳飾り（耳飾りを省く案も含める） | 案 |
| 2c | 黄色い服（明暗の置き方で2〜3案） | 案 |
| 3 | 弓の構え（左手で弓、右手で弦にかけた矢、交差の角度で2〜3案） | 案（コマ全体と、弓の部分の拡大） |
| 4 | `base` の残り3方向（手前と奥は `types/unit/SPEC.md` の表のとおり。左手の弓は `down` で画面右・手前） | `contact_sheet.py --columns 4` |
| 5 | 待機の2コマ目（何を動かすかで案を並べる）と歩き（脚だけ） | `sheet.py` のプレビュー |
| 6 | 攻撃 `atk_wind`・`atk_hit`・`atk_release`。正面と横向きで案を並べる | 案、`sheet.py` のプレビュー |
| 7 | シートを書き出し、ゲームと anim-page で確かめる | anim-page の Artifact、ゲームの画面 |

段階1〜6で守ること:

- 足元 y=30・左右中央・背丈 24〜26px（頭頂 y=5）。`unit` に mirror を使わない（`left` と `right` は別々に描く）
- 奥にあるものは体に重なる部分を描かず、色は手前と同じ階調にする（立ち絵の規約）
- バンダナと服・肌が接するところは輪郭で分ける
- 目の上端の行は4方向で揃える

段階7の確かめ方:

- `tools/validate.py`、`tools/check_colors.py`（既存の `types/face/reference/knight.txt` の1件は範囲外の既知の失敗）
- `tools/sheet.py sheets/ines.txt` のプレビューで足元と中心を見る
- `tools/export.py` で `ines-map.png` を書き出し、`npm test`・`npm run build` を通す
- ゲーム側の `tools/anim-page.py` でページを作り、Artifact として公開する（ロランのページとは別の URL）
- ゲームを CDP で撮り、矢が出る瞬間と `atk_release` が合っているかを見る
- `contact_sheet.py` でロランと並べ、型をまたいだ絵柄のずれを見る

## 規約と記録

- `pixel-asset-forge/types/unit/SPEC.md`:
  - **弓の持ち方の節を新しく設ける。** 左手で弓、右手で弦にかけた矢、待機での交差、4方向の手前と奥、各部品の色と専用の文字を、段階3・4で決まった形から文章と座標で書く
  - 構成の例外: 弓の `attack` は `[atk_wind, atk_hit, atk_release]`（理由は矢の出る時刻）
  - 弓の攻撃の3コマの規約と、弓のユニットの待機の2コマ目で何を動かすか
  - ファイル配置の表に `female_*` を足す。未確定の色数の行にイネスの実測を足す
- `pixel-asset-forge/ISSUES.md`:
  - 「剣が `stone_*`、盾が `metal_*`」の行に、イネスの黄色い服も `metal_*` であることを足す
  - 「手の描き方が持ち物で変わる」の行に、弓の持ち方を文章の規約にしたことを足す
  - 「`unit` が1体しか無い」の行を2体（ロラン・イネス）に直す。「素体は暫定」の行に `female_*` のことを足す
  - 「`breathe` という名前と中身が合っていない」は「2体目を作るときに決める」となっているので、段階5で名前をどうするかを依頼者に確認する
- `pixel-asset-forge/CLAUDE.md`: 「手本は `assets/unit/roran/`」を、イネス（弓の手本）も含む書き方に直す
- `HANDOVER.md`: 決めたこと、各段階で選ばれた案、マージのときの注意（パレットに `orchid_*` を足したので、`feat/roran-face` とぶつかるかを `git merge-tree` で確かめた結果）
- **規約に書くもののうち、ロランにも当てはまるものが出たら、規約に書く前にロランに当てはめた案を描いて見せる。**
  弓の持ち方と攻撃の3コマ目は弓のユニットだけの規約なので、ロランには当てはめない見込み
