2026-11-17。`npm run balance`（40 シード）の記録。作成時点のログ。設計は `2026-11-16-growth-classes-design.md`。

勝率は「1 回目の勝率」。測り直すたびに、何を変えたかと表をこの文書に足す。

## 1. 測り方の直しの後（成長は工程 3 のまま）

ボットが敵を残したままゴールに入らないようにした（設計「7. 勝率の測り方と目標」）。ゲームの決まりは変えていない。

直した所（`src/core/balance.ts`）:
- 敵・説得の相手・村への `move` の目的地を、ゴールの半径 + 20 の円の外へ押し出す（`goalSafeDest`）
- 押し出した先が石などの歩けないマスだと、ゲームが最寄りの歩けるマスに置き換え、それがゴールの中になる。s6 では湧き位置 (240,80) がゴールの中で、その石の裏がこれにあたった。歩けるマスの中で円の外の最も近いマスへ寄せる（`walkableSafeDest`）
- s6 は、敵のいる左上の部屋へ行く最短の道が、ゴールのある上の通路を通る。円の中を歩けないことにした地図で道を作り、直進できて円を通らない先の点を途中の目的地にする（`routeAvoidingGoal`）
- 駆け抜ける・急降下などの目的地を取る技も、同じく円の外へ押し出し、途中で円を通る向きのときは出さない

### 読み取り

- 直しだけでは勝率はほとんど動かなかった（s6 は 97.5 のまま、s7 は +7.5 で標準偏差約 ±7% の範囲）。敵が残ったまま勝っていた分が、直した後も勝ちのままか負けに変わったかは、切り分けていない
- 直した後の stage3 の平均レベルは 10.4（出撃した 8 人の、クリア後）。設計の背景にある「8.2」は加わった仲間全員（控えを含む）の平均なので、同じ範囲で測り直した値は 10.4。目標の 15〜18 まで約 5〜8 足りない
- 通しの帯の外は s4（下に 2.5）・s7・s9・s10・s3。育てた場合の帯の外は s7・s9・s10・s3。工程 3 の成長（HP +1・3 レベルごとに攻撃 +1）では、育てても勝ちやすくならない（s9・s10 は +3 しても通しと同じか少し上）。この差を作るのが Task 2 以降
