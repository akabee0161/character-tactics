# ロランの顔グラを forge で描く（issue #23 の1番目）設計

作成: 2026-09-30

## 目的

今の顔グラ（`assets/images/*-face.png`）は 128px のフリー素材で、64px と 32px の枠に縮小して描いている。この水準の顔グラを pixel-asset-forge（以下 forge）で作れるようにする。題材はロランとし、ここで固めた描き方を後の作業とほかのユニットに使う。

issue #23: https://github.com/akabee0161/character-tactics/issues/23

## issue #23 の進め方（依頼者と合意、2026-09-30）

issue の5項目を、次の順で1つずつ設計 → spec → 計画 → 実装する。この spec は1番目だけを扱う。

1. ロランの顔グラを今の素材の水準で forge で描く（この spec）
2. 顔グラを入力にして、ユニットに特徴を反映する。ユニットの目を大きく（少し縦長に）するのもここで行う
3. 剣・弓のアイコンを生成する（item 型の 16px。役割アイコンと持ち物の元絵を兼ねる）
4. アイテムを入力にして、ユニットの持ち物に反映する
5. その後、ほかのユニットに移る

一番失敗しやすい顔グラを最初にし、目の形は顔から決まるので目の修正を2番目に含めた。

## 決めたこと

依頼者の判断（2026-09-30）:

- 顔グラは**ドット絵（テキストのグリッド）で描く**。どうしても目標の品質に届かなかったときに限り、Stable Diffusion などで作った画像（または、SD の下絵を減色してグリッドを手で直す中間の案）を検討する
- 見た目は**今のフリー素材のロランを引き継ぐ**（紺がかった黒髪、暗い色の鎧）
- 大きさは README の規約どおり **64×64**
- 合格の判定は、**64px の絵を拡大して 128px の元絵と並べ、描き込みの質（形・陰影・表情）で見劣りしないか**を依頼者が見る。細かさ（解像度）は比べない
- 描き方は、**元絵を見本として横に置き、段階を踏んで手で描く**。元絵を縮小・減色して下絵にする方法（元絵の無いキャラクターに使えず、素材の規約の確認も要る）と、部品を組み合わせる道具を作る方法（顔1枚の段階では先走り）は採らない

## 作るもの

### 絵

- `pixel-asset-forge/assets/face/roran.txt`（64×64 のグリッド）
- ヘッダは face 型の規約どおり: `# type: face`、`# size: 64x64`、`# light: upper-left`、`# bg: gradient:#1c1834->#323256`、輪郭は全周に1px

### 規約

- `pixel-asset-forge/types/face/SPEC.md` の寸法を `32x32` から `64x64` に直す。背景・光源・輪郭・構成要素（肌4段・髪4段・目・口・衣服3段）はそのまま
- 描いたロランが合格したら、face 型の新しい手本として `types/face/reference/` に置く。今の 32px の `knight` を旧規約の手本として残すか消すかは、そのときに依頼者に確認する
- forge の `CLAUDE.md` の「確定済み: 解像度は `face` = 32x32」も 64x64 に直す

### 色

- 髪と鎧に要る色は `pixel-asset-forge/palette/master.json` に足す
- 足す前に `tools/probe_colors.py` で、隣り合わせる予定の色と区別できるかを測る（forge の原則）。足した後に `tools/check_colors.py` も通す

### 並べて見る道具

- 64px の絵の8倍と、元絵の4倍（どちらも 512px）を横に並べた画像を出す小さな道具を `pixel-asset-forge/tools/` に足す。1枚ずつ見せるのでは比べにくいため
- `tools/` に手を入れるので、テストを `pixel-asset-forge/tests/` に足す。テストは現役のアセットを読まず、`tests/fixtures/` か一時ファイルの絵を使う（forge の原則）

### ゲームへ渡す

- `sprites.json` に `"face/roran.png": "roran-face.png"` を足し、`export.py` で書き出す。今の 128px のフリー素材はこれで上書きされる
- **ゲームのコードは変えない。** `FACE_PX`（`src/ui/layout.ts`、64 と 32）と `smoothFor`（`src/render/sprites.ts`、縮小のときだけぼかす）は、64px の顔を前提に作ってある

### 記録

- README「アセットの大きさの規約」と `assets/images/README.txt` の「今ある顔は規約より大きい」を、ロランの分だけ直す
- face を 64px にしたことを `pixel-asset-forge/UPSTREAM.md` の「forge に戻す候補」に書く
- 作業中に見つけて直さないものは `pixel-asset-forge/ISSUES.md` に書く

## 描き方

段階ごとに `validate.py` と `render.py` を通し、並べた画像を依頼者に Read で見せ、直す点を決めてから次の段階へ進む。

1. **シルエット** — 頭・髪・首・肩の外形と輪郭線だけ。SPEC に書かれた knight の弱点（髪がヘルメット状、輪郭が長方形で頭蓋の丸みが無い、首が太く肩との境目が不明瞭）をここで解消する
2. **色の塊** — 肌・髪・目・鎧を陰影なしの基本色で塗る
3. **陰影** — 左上からの光で、明るい色と影の色を置く。髪は毛束と流れが見えるようにする
4. **仕上げ** — 目（眉と上まつげを分ける）・口・鎧の縁の光など、表情と細部

**届かなかったとき:** 直しても届かないと依頼者が判断したら、そこで止めて報告する。SD（または中間の案）を検討するかは、その時点で依頼者が決める。

## 確認

- forge: `validate.py`・`check_colors.py`・unittest（`-m unittest discover -s tests`）が通ること。`contact_sheet.py` を更新する
- ゲーム: `npm test` と `npm run build` が通ること。書き出した後に CDP で次の画面を撮って依頼者に見せる
  - 64px の枠: 会話・セリフ欄
  - 32px の枠: 仲間一覧・下のバー

## 環境

この端末には forge の `.venv` も uv もまだ無い（2026-09-30 時点）。描き始める前に、forge の CLAUDE.md の手順どおり uv を入れ、Python 3.14 の venv を作る。uv のインストールは依頼者の承認を得てから行う。
