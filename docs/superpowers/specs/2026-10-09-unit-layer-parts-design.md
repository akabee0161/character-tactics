# ユニットを層（パーツ）で組み、重なり順をデータで持つ（試作の設計）

- 日付: 2026-10-09
- 対象: pixel-asset-forge の敵ユニット（`cand/enemy-frames/`）。試作は槍の女性 a（`spear-thug-a-f`）の `left` 6コマ
- 提案: 依頼者（「基本パーツを先に作り、重なり順を持って組む」）
- 台帳: `.superpowers/sdd/2026-10-06-enemy-variants/progress.md`

## 1. 目的

今の敵のコマは、完成した素体の上に武器や拳を上書きして作っている（`cand/gen/mkframes.py`・`mkweapons.py`）。
上書きした時点で「どの画素が何の部品か」が消えるので、奥か手前かを絵から推測するしかない。
前回までの不具合（奥の手が髪や体の手前に出る、拳が体の手前に浮く、拳と体の境に輪郭が無い、柄と拳のずれ）の多くは、この推測の誤りだった。

部品を層として持ち、向き×状態ごとの重なり順の表で合成すれば、奥行きは表で決まり、Claude が自分で防げる。

## 2. 成功の条件

1. 試作の6コマで、奥の拳が長い髪（背中）の後ろに入るなどの前後が、合成だけで正しく決まる
2. 「奥の層が手前の層の上に出た」を、層の順番を比べるだけで機械的に検出できる
3. それ以外の見た目は、今の承認済みの絵からなるべく変えない（変わった画素は比較ページで示す）

## 3. 決めたこと（2026-10-09 依頼者と合意）

### 3.1 進め方は案2（腕・拳・髪・武器だけを層にする）

- 頭・胴・脚は1枚の「芯」にまとめる。前回までの不具合は、すべて腕・拳・髪・武器の前後で起きていて、頭・胴・脚の前後では起きていない
- 後で案1（頭・胴・脚も別の層にする）へ移る可能性がある。**道具と表は層の数を決め打ちしない**。
  移るときに増えるのは、芯の切り分け（男女×4方向×立ち・待機2、約16枚）と表の行の追加、境目の輪郭
- 案3（絵は今のまま、画素ごとの部品名の表を添える）は、検出はできても防げないので採らない

### 3.2 層

| 層 | 中身 | 元にするもの |
|---|---|---|
| 芯 | 素体（頭・胴・脚）、目、服の飾り（ベルト・ぼろ） | `cand/enemy/female_body_noarm_left.txt`（奥の腕なし）から手前の腕を除いたもの、`eye_*`、`cloth_*_female_*` |
| 手前の腕・拳 | 手前側の袖と拳 | 素体から切り出す |
| 奥の腕・拳 | 奥側の袖と拳（武器を握る手）。影の色で描く | 立ち・待機2・歩きは `mkweapons.py` の `FIST_FAR_L`（2px 幅）。攻撃は今のパッチ |
| 長い髪（頭） | 頭を覆う髪と前髪（肩の高さまで） | `cand/enemy/hair_<型>_<向き>.txt` |
| 長い髪（背中） | 肩より下に垂れる髪 | `cand/enemy/hair_<型>_back_<向き>.txt` |
| かぶり物 | バンダナ・兜など（女性 a は無し） | `cand/enemy/head_<名前>_<向き>.txt` |
| 武器 | 槍 | `mkweapons.py` の槍 |

- 芯は6コマで共通。歩きの2コマだけ、脚（y=28〜30）を `cand/enemy/female_walk_<a・b>_left.txt` に差し替える（今の `mkframes.py` と同じ）
- 長い髪を2枚に分けるのは、1つの髪の中に「芯より手前（頭を覆う所）」と「芯より後ろ（胴の後ろに垂れる所）」が混ざっているため。
  1つの層は前後の位置を1つしか持てない。LPC キャラクタージェネレーターも、尾を体の手前の層と奥の層の2枚に分けて持つ
  （`sheet_definitions/body/lizard/tail_lizard.json`、zPos 85 と 5。2026-10-09 に一次情報で確認）
- かぶり物が髪より手前なのは、頭まわりの中での順。全体で一番手前は手前の腕・拳

### 3.3 left の重なり順の表

| 状態 | 奥 ← → 手前 |
|---|---|
| 立ち・待機2・歩き2コマ・振りかぶり・当たり | 武器 → 奥の腕・拳 → 長い髪（背中）→ 芯 → 長い髪（頭）→ かぶり物 → 手前の腕・拳 |

- 振りかぶりの奥の拳は**胴の後ろ**（依頼者の判断。今の絵は胴の手前に描いていて、前回の指摘「left の1コマ目の奥の拳が体の手前に浮いて見える」はこのこと）。
  見本は `pixel-asset-forge/build/spear_wind_far_fist.html` の B
- 当たり（突き）は、拳と槍が体の向こう側を通り、芯と髪に隠れる（今の絵と同じ）
- 待機2で、奥の拳が長い髪から 1px 幅だけはみ出す件（槍の女性 a・b）は、この順で合成すると拳が髪の後ろに入る。拳は髪から外れた部分だけが見える

## 4. 作り方

1. **部品を作る**: 3.2 の元から層を切り出す。各層は自分の輪郭を一周持つ（拳と体の境の輪郭は、手前に重なった層の輪郭として入る）
2. **取り付け点**: 奥の拳に「握る点」を持たせ、槍は握る位置（穂先から12px、SPEC の規約）をそこに合わせて置く。
   女性用の武器のずらし量の表（`FEMALE_SHIFT`）は使わない
3. **合成**: 表の順に、手前の層の画素で上書きする。コマごとに「どの画素がどの層から来たか」の対応表も書き出す
4. **合成した後の輪郭**: `tools/hand_outline.py` の `close_hands` で手の輪郭を閉じる。ほかの境目の輪郭を足す工程は、試作で要ると分かったときだけ足す
5. **置き場所**: 試作の道具は `pixel-asset-forge/cand/gen/` に置き、出力は `cand/layer-trial/`。採用が決まったら、テスト付きで `tools/` へ移す

## 5. 確かめ方

- 今の `tools/weapon_check.py` を、槍の女性の SPEC の指定（`--ref`・`--far`・`--cover`・`--far-shade`）で通す
- 新しい検査「書き出したコマが、表の順で合成し直した結果と同じか」を作る（手で直して順が崩れたら落とす）。
  **入れる前に、承認済みの絵に掛けて誤検出を数える**（前回足した4つの検査は、どれも最初の案で誤検出が出た）
- 比較ページ: 今の絵と試作を6コマ並べ、層ごとに表示を切り替えられるようにする。変わった画素を示す。依頼者に見せて承認を取るまでコミットしない

## 6. 範囲外・弱いところ

- 範囲外: 他の向き（down・up・right）、他の敵、ガウ・ロラン、男性の振りかぶりの拳を胴の後ろに直すこと（試作の結果を見て扱う）
- 手前の腕を素体から切り出すのは手作業の判断。切り方で見た目が1〜2画素変わることがある
- 腕を曲げたポーズのような状態ごとの形や、層の境目の輪郭は、層にしても描く判断が残る。自動になるのは前後関係まで
- 頭・胴を状態ごとに違う形で持つ必要が出たら（例: 攻撃で体をひねる）、案1への移行は約16枚では済まない
