# 左右の向きで武器の位置がそろっているかを確かめる道具（PR ウ）設計

2026-10-27。依頼者と brainstorming で決めた（2026-10-25〜27）。D（敵16体の組み直し）の前の道具。
`pixel-asset-forge/ISSUES.md` の「左右の向きで武器の位置がそろっているかを確かめる道具が無い」と

## 目的と経緯

ロランの `left_atk_hit` は、2026-10-11 の組み直しで「剣ごと体に隠れる」として剣と剣の拳を空の部品にした。
依頼者が動きのページで見て、剣が見えないのがおかしいと気付いた（2026-10-21）。今の道具はこれを拾えない:

- `tools/hand_mirror.py` は拳だけを比べ、攻撃のコマ（`atk_*`）は比べない（2026-10-12 依頼者の判断「攻撃は動きの表現で位置がずれることが多い」）
- `tools/weapon_check.py` は `checks/roran.json` の `hidden` に `left_atk_hit` があるので、剣が無いことを通す

依頼者の判断（2026-10-25）:

- おかしいと感じた決め手は「剣が見えないこと」
- 確かめ方は「left と right の剣の位置を反転させて、ずれていないかを見る」
- down と up は比べない
- 道具が拾ったら「落ちる」（`unit_rules.py` の NG と同じ扱い。例外は基本的に作らず、正しい絵が落ちたら判定を直す）

## 実測（今の3体、2026-10-25）

left の各コマについて、拳が握る部品（剣・盾・短剣・弓・矢）ごとに、left の部品の画素の位置と、同じ状態の right の部品の画素を
左右反転（x → 31 − x）した位置を比べた。体に隠れる画素も比べ、色は比べない。34組のうち30組は完全に一致した。
体（芯）は3体の全コマで反転すると一致する。合わない4組:

| ユニット・コマ | 部品 | 違い |
|---|---|---|
| ロラン `atk_hit` | 剣 | left が空（right 反転は61画素） |
| ロラン `atk_wind` | 剣 | 形は同じで、横に1画素ずれる |
| ガウ `atk_hit` | 短剣 | 形は同じで、横に1画素ずれる |
| ガウ `atk_wind` | 短剣 | 位置は同じで、形が違う（left だけに1画素、right 反転だけに3画素） |

依頼者の判断（2026-10-27）: 4件とも直すべきずれ。したがって、この確かめ方の偽陽性は今の絵で0件。

## 10-12 の判断との両立

「攻撃のコマは動きの表現で位置がずれることが多いので比べない」は、**拳の位置の決まりとして残す**（`hand_mirror.py` は変えない）。
武器は攻撃のコマでも比べる。今の絵で武器のずれた3件が、どれも動きの表現でなく直すべきずれだったため。
`types/unit/SPEC.md`「部品で組む規約」の拳の位置の項の隣に、武器の決まりとして1項を足す。

## 道具

- **比べる組**: left と right の同じ状態のコマ（`left_<状態>` と `right_<状態>`）。攻撃を含む全状態。down と up は比べない
- **比べる部品**: 設定（`checks/<ユニット>.json` の `parts`）で、拳の `grips` に書かれた部品（拳が握る物。今の3体では剣・盾・短剣・弓・矢）。
  髪・かぶり物（`head`）や役割の無い部品は比べない（Claude の判断。左右で形の違う髪は普通にあり、この道具は持つ物の位置を見るため）。
  部品の名前は、部品のファイル名の「_<向き>_」より前（`hand_mirror.py` と同じ見分け方）
- **比べるもの**: 部品の空でない画素の位置（部品の dx・dy を足したコマ上の位置）。left の位置と、right の位置を x → 31 − x で反転したものが**集合として一致**するか。
  色は比べない（光源が左上に固定なので、反転した部品は陰の付き方が変わる。`hand_mirror.py` と同じ理由）。体や手前の物に隠れる画素も比べる
- **落ちる場合**: 位置が一致しない／部品が片方にしか無い／片方の部品が空で、もう片方が空でない。両方とも空なら一致とみなす（イネスの `atk_release` の矢）。
  `left_<状態>` か `right_<状態>` の片方しか無いときも落とす
- **出力**: `hand_mirror.py` と同じ形。失敗は「FAIL 」で始め、「:」より前を left のコマの名前にする（`unit_rules.py` の例外の照合に合わせる）。
  合わない画素の位置（left だけ・right 反転だけ）を出し、直す人が赤枠のページを作らなくても場所が分かるようにする
- **入口**: `tools/unit_rules.py` から走らせる（`checks/<ユニット>.json` を受ける確認の並びに足す）。単独でも走らせられる
- **テスト**: `tests/fixtures/` に固定した小さな compose の設定で、一致・1画素ずれ・片方が空・両方が空・組の片方が無いを確かめる（`tests/test_no_live_assets.py` に従い、生きているアセットは読まない）

## 直す絵（この PR で直す）

道具を入れた時点で、`unit_rules.py` はロランとガウで NG になる。次の4件を直して 0 件にする。

1. **ロランの `left_atk_hit` の剣**: 剣と剣の拳の部品（今は空）を描く。`right_atk_hit` を反転した位置に、体の前（画面左）へ振り下ろした剣を出す。
   重なり順は今の `left` のまま（剣・剣の拳・芯・盾の拳・盾）。剣が体に隠れる所は隠れてよい。
   `types/unit/SPEC.md` の「剣ごと体に隠れるコマ」から `left_atk_hit` を外し、`checks/roran.json` の `weapon_check.hidden` からも外す
2. **ロランの `atk_wind` の剣**（1画素の横ずれ）
3. **ガウの `atk_hit` の短剣**（1画素の横ずれ）
4. **ガウの `atk_wind` の短剣**（形の違い）

2〜4 は left と right のどちらに合わせるかが決まりから出ないので、両方の案を並べたページを見せて依頼者が選ぶ。
直した絵は、前と後を並べたページ（静止と動き）で見せて承認を得てからコミットし、ゲームのシートを書き出して動きのページを出し直す。
拳の部品を動かすときは、`hand_mirror.py`・`fist_check` など既存の確認も通るようにする。

## 文書

- `pixel-asset-forge/types/unit/SPEC.md`「部品で組む規約」: 武器の位置を left と right で合わせる決まり（攻撃のコマも含む）と、確かめる道具の名前
- `pixel-asset-forge/README.md`・`pixel-asset-forge/CLAUDE.md` のコマンド一覧に道具を足す。`unit_rules.py` の docstring の確認の並びも合わせる
- `pixel-asset-forge/ISSUES.md`: 上の2行を消す

## しないこと

- down と up の武器は比べない（依頼者）
- 拳の比べ方（`hand_mirror.py`）は変えない。攻撃のコマの拳は比べないまま
- 部品の色・陰は比べない
- 例外（`exceptions`）で通す運用はしない。正しい絵が落ちたら判定を直す
