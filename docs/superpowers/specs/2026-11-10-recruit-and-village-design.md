# 仲間が増えるイベントと村の訪問 設計

2026-11-10 依頼者と合意した内容。「（Claude の判断）」と書いたものは、依頼者が決めていない点を Claude が決めたもの。

## 目的と背景

今は仲間 4 人（ロラン・イネス・ミスト・ガウ）が全ステージで最初からそろっていて、マップの村は通れない飾りのマスでしかない。依頼者は次の 2 つを望んでいる。

- 冒険の途中で仲間が増えていくこと
- 村を訪れると何かが起きること

この作業は、依頼者が決めた 5 つの課題（仲間のイベント → 村のイベント → 難易度の調整 → 敵の絵 → タイル）の 1・2 番目にあたる。仲間の数と加わる時期は難易度に響くので、難易度の調整より先に行う。

## 目標

1. 新しい仲間を 4 人足し、仲間は最大 8 人にする
2. 仲間が加わるきっかけを 3 通り作る
   - **説得**: 特定の仲間が特定の敵に近づくと会話が始まり、その敵が仲間になる
   - **村**: 戦闘中に仲間を村まで歩かせると加わる
   - **開始時**: ステージの最初の会話のあとに加わる
3. 村を訪れたときに起きることを作る。仲間が加わる村のほかに、次の 5 種類の村を作る
   - 会話だけ
   - 仲間全員の体力が回復する
   - 攻撃力が上がる
   - 経験値がもらえる
   - 能力値が上がる
4. 戦闘中の下の段を 1 段×8 枠にして、8 人分の顔を並べる

## 目標にしないこと

- **新しい 4 人の本番の絵**: この作業では仮の絵で作る。本番の絵は後から 1 人ずつ、今のユニットを描く手順で描く（別の作業）
- **難易度の調整**: 新しい 4 人の強さは役割に合う仮の数値にとどめる。敵・ステージを含めた調整は 3 番目の作業で行う
- **出撃メンバーを選ぶ画面**: 加わった仲間は全員が出撃する
- **タイルの絵**: 村を新しく置くステージでも、タイルは今の絵か単色のまま（5 番目の作業）

## してはいけないこと

- 一度きりのごほうび（経験値・能力値・仲間の加入）を、ステージのやり直しで何度も受け取れるようにしない
- 加わる会話を、戦闘を止めずに流さない（依頼者の指定。読み落とすと誰が加わったか分からない）

## 決まったこと（依頼者）

### 仲間

- 新しい仲間は 4 人。今の 4 人はそのまま
- 役割: 1 人は防御役、1 人は魔法。残り 2 人は Claude が案を出す（下の「新しい 4 人の案」）
- 名前・人物像・加わる場面の会話、どのステージでどのきっかけで加わるかの割り振りは、Claude が案を出す
- 戦闘中に加わった仲間は、そのステージのうちから戦う
- 説得の相手を倒してしまった、または村に着く前にステージが終わったときは、その仲間は手に入らないままでよい
- 加わるときのレベルは仲間ごとに決める
- 新しい 4 人の名前を後から変えやすくする。今の 4 人は名前（`roran` など）がユニットの ID・ファイル名・フォルダ名・セリフのキー・セーブのキーに入っていて、名前を変えるのに手間がかかる。新しい 4 人はそうならないようにする（下の「新しい仲間の ID と名前」）

### 加わる会話

- 説得と、仲間が加わる村の会話の間は戦闘を止める。会話の見た目は、今のステージ開始時の会話と同じ（タップで送る）

### 村

- 戦闘中に仲間を村まで歩かせて訪れる
- 体力の回復は仲間全員に効く
- 攻撃力アップは、そのステージが終わるまで続く
- 攻撃力アップ・経験値・能力値は、訪れた 1 人だけに効く
- 能力値の村で何が上がるかは、村ごとに決める

### 説得の相手

- 説得の相手は、ほかの敵と同じに扱う。仲間は自分から攻撃し、相手も仲間を攻撃する。決められた仲間が近づいたときだけ説得が始まる

### 受け取ったものが残る時期

- 戦闘中に加わった仲間と、村でもらった経験値・能力値は、そのステージをクリアしたときだけ残る（今の経験値と同じ決まり）。負けたら、そのステージで加わった仲間もいなくなる
- 一度きりのごほうびを受け取った印も、クリアしたときだけセーブに書く。負けたら、やり直しでもう一度受け取れる

### すでに遊んでいるセーブ

- 加入をクリア済みのステージに置いた場合も、自動では渡さない。そのステージをやり直せば手に入る

### 下の段

- 1 段×8 枠（見本の案 B、https://claude.ai/artifact/HAh4LEYY6AXzM5MDAcvPDC ）。1 枠は横 64×縦 80。顔（40px 角）・役割の小さい絵（16px）・HP・技のゲージを出し、名前と Lv は出さない
- 今と同じく、枠を押すとその仲間を選び、必殺技を出す。黄色い縁・倒れたときの暗さも今と同じ

## Claude の判断で決めたこと

- **村の訪問の判定**: 村のマスは今と同じく通れない。仲間の足元の箱が村のマスに隣り合う位置まで来たら訪問とする。最初に着いた 1 人が「訪れた人」になる。1 つの村を訪れられるのは 1 ステージに 1 回。訪れた村は見た目を少し暗くし、もう何も起きないことを示す
- **会話だけの村・回復・攻撃力アップの村**: 戦闘は止めない。下の段のセリフ欄に、今の戦闘中のセリフと同じく数秒だけ出す。止めるのは仲間が加わる会話だけ（依頼者が止めると決めたのは加わる会話）
- **一度きりのごほうび**: 経験値・能力値・仲間の加入は、その村（または説得・開始時の加入）ごとに、クリアして持ち帰れたのが最初の 1 回だけになるようにする。回復・攻撃力アップは、やり直しでも毎回起きる
- **攻撃力アップの重なり**: 同じ仲間が攻撃力アップの村を 2 つ訪れたら足し合わせる。ノエルの「はげます」とも重なる
- **能力値**: 上がった分はその後のステージにも残る。上げられるのは HP・攻撃・守り・移動の速さのどれか
- **敵と村**: 敵は村に入らず、村に何もしない
- **戦闘中に加わる仲間の出る位置**: 説得なら、その敵がいた位置に仲間として現れる（敵は消える。倒した扱いにはしないので経験値は入らない）。村なら、訪れた仲間の隣に現れる。加わったときの体力は満タン
- **開始時に加わる仲間**: ステージの開始時の会話のあと、配置の前に加わり、ほかの仲間と同じく配置できる
- **説得できる敵**: 説得の相手は、ならず者などの一般の敵ではなく、仲間になる本人が敵側にいる形にする。説得できる敵には、頭上に目印を出す（どの仲間を近づければよいかは、ステージ開始時の会話でにおわせる）
- **説得が始まる距離**: 決められた仲間と説得の相手が 2 マス（64px）以内に入ったとき。決められた仲間が倒れているか出撃していなければ、説得はできない
- **やり直したステージでの加入**: すでに加わった仲間は、重ねて加わらない。説得の相手は、加入済みならそのステージに出てこない
- **出撃と配置**: 加わった仲間は全員が出撃する。ステージの `placement.starts` は 8 人分を並べられるようにする（足りないときに先頭から繰り返すと立ち位置が重なるので、8 人分を書くか、重ならない位置を自動で決める。どちらにするかは作る人に任せる）
- **ほかの画面の仲間の一覧**: ステージ選択とリザルトの仲間の一覧は、今は 1 列に縦に並べている。8 人だと入らないので、2 列にする

## 新しい仲間の ID と名前（依頼者の要望を Claude が具体化）

- 新しい 4 人の ID は、名前と関係のない `ally05`〜`ally08` にする。ID は一度決めたら変えない（セーブが参照する）
- 名前が入るのは、ユニットの JSON の `name` と、会話・セリフの本文だけにする。ID を使う場所（ユニット・敵の JSON のファイル名、`assets/images/` の画像の名前、`pixel-asset-forge` の部品・ユニットのフォルダ名、セリフのキー、セーブのキー）には名前を入れない
- 説得の相手として敵側にいる本人も、敵の定義の ID を名前と関係のない形（例: `ally06-foe`）にする
- 会話・セリフの本文で新しい 4 人の名前を書くときは、名前を直書きせず、ID から名前を差し込む書き方（例: `{ally06}`）を使えるようにする。名前を変えるときに直すのがユニットの JSON の `name` 1 か所で済むようにするため
- 今の 4 人（`roran` など）の ID は変えない（この作業の範囲外）

## 作る人に任せること

- ステージの JSON に村・説得・加入をどう書くか（今の `intro` や `spawners` と同じく、ステージの定義に書き足す形を想定）
- セーブの形と、版を上げたときの古いセーブの引き継ぎ（今の `reconcile` の方針: 壊れた部分だけを捨て、進行は失わない）
- 村をどのステージのどこに置くか（6 種類の村をどれも 1 回は置く）
- 会話の文面
