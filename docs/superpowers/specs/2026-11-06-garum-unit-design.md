# ガルムのマップ用ユニットを部品から作る（設計）

2026-11-06。依頼者との相談（brainstorming）の結果。

## 目的と理由

ガルム（敵・最後のステージのボス。`assets/enemies/garum.json`）のマップ用の絵は、今は仮の絵（`assets/images/garum-map.png`）で、
48px のコマの中にほかのユニットと同じくらいの小さな体が入っているだけ。顔グラ（`assets/images/garum-face.png`）とも似ていない。
味方4体と敵16体は部品から組み直し済みで、残る `unit` はガルムだけ（`pixel-asset-forge/ISSUES.md`）。

依頼者がいちばん望むこと: **ロランたちと比べて大きく、強そうに見える。**
そのためにコマは 48px のまま、体をコマいっぱいに描く（ロランたちの 32px の体の約1.5倍）。

forge の確認の道具はロランからミストまでを 32px で作ってきたため、32 の決め打ちが多い。
そこで **先に道具を 48px でも動くように直す PR を出し、その後にガルムを描く**（依頼者が合意。D の前に道具をそろえたときと同じ進め方）。

## 見た目（依頼者の言葉）

- ロランたちと比べて大きく、強そうに見えてほしい
- 大きな剣と盾を持っている。剣を叩きつけるように攻撃する
- 体は鎧に包まれている
- 見た目は今の顔グラに合わせる
- 剣を叩きつける攻撃で「これだけは外したくない」点は無い（依頼者）

## Claude の推測として依頼者に示し、「違っているところは無い」と返ったもの

- 顔グラに合わせる: 角のような飾りの付いた暗い兜、全身を包む鎧、赤と青の色
- 顔は兜で隠れるので、目の部品は兜のすき間の暗い所として描く
- 剣は大きさで強さが伝わるよう、ロランの剣より明らかに長く太く描く
- 攻撃は今の JSON どおり3コマ `[atk_wind, atk_hit, base]`。`atk_wind` で剣を頭の上へ振り上げ、`atk_hit` で前の地面へ叩きつける。
  待機2コマ・歩き4コマも今のまま
- 部品は 芯・兜（被り物）・目・鎧（服）・拳・剣（武器）・盾 に分ける。手順はミストと同じ
- 書き出す `garum-map.png` は今と同じ 48px × 4列 × 12行（192×576）

## 決めたこと（依頼者の判断、2026-11-06）

- **コマは 48px のまま**。`frame=48` を32pxに変えない。SPEC の「未確定」の「フレームサイズ」を「確定している規約」へ移す
- **48px の体の比率は、32px の値をそのまま1.5倍にする**: 足元 y=30 → y=46（ゲームの `bodyCenter` のテスト「48px のコマでは 22px 上」と一致する）、
  背丈 24〜26px → 36〜39px、ほかの行の決まり（脚の始まり、頭・胴・脚の行の範囲など）も1.5倍
  - 行の値は **足元からの距離を1.5倍** して移す（Claude の判断）。足元は y=30 を単純に1.5倍した 45 でなく、ゲームの `FOOT_INSET = 2`（コマの下から2px）を保った 46。
    例: 歩きで動いてよい脚の行 y=28〜30（足元から0〜2）→ y=43〜46、`unit_check` の脚の始まり y=24（足元から6）→ y=37。
    頭頂の行（`blade_height` の `TOP = 5`・`IDLE2_TOP = 3`）も同じく足元から測る（25 上 → 37.5 上）。端数の丸め方は作る人が決めて SPEC に書く
- **攻撃の火花・矢などのエフェクトの大きさと位置は今回の範囲に含めない**。`src/render/draw.ts` の `EFFECT_R`・`BODY_LIFT` は
  32px のユニットに合わせた簡易対応のままなので、ガルムに当たった火花が胸でなく腰のあたりに出るかもしれない。目立ったら別の作業で扱う

## 第1段階: 道具を 48px でも動くようにする（先に PR）

forge の道具の 32 の決め打ちは2種類ある（Claude が `grep` で数えた。動かすと増えるかもしれない）。

1. **大きさの決め打ち**（約15ファイル）。コマのファイルの `# size:` から大きさを読むように直す。
   例: `layers.py`・`cut_layers.py` の `SIZE`、`parts_export.py` の `WHOLE`、`weapon_check.py` の枠（x=0,31）、
   `weapon_mirror.py`・`hand_mirror.py` の左右反転（31 − x）、`unit_config.py` の座標の範囲（0〜31）、
   見せるページ（`anim_compare.py`・`enemy_gallery.py`・`unit_picker.py`）、`compose.py` の説明
2. **体の比率の決まり**（約5ファイル）。コマの大きさに応じて値を選ぶ（32px の値 ×1.5）。
   例: `sheet.py` の `FOOT_Y`、`height_check.py` の背丈と足元、`unit_check.py`・`still_check.py` の脚の行、`body_check.py` の行の範囲の既定値

守ること:
- **32px のユニット（味方4体・敵16体）の判定は1件も変わらない**。今の全ユニットに `unit_rules.py` と `compose.py --check` を直す前と後でかけ、結果が同じことを確かめる
- 直した所には 48px のコマでのテストを足す（TDD）
- SPEC（`types/unit/SPEC.md`）の「確定している規約」に 48px の行（解像度・足元・背丈）を足す。forge の README・CLAUDE.md と ISSUES.md の該当行も直す

## 第2段階: ガルムを描く

### 依頼者に見てもらう所（4回。ミストと同じ）

道具で落ちたものは Claude が道具に従って直す（`CLAUDE.md`「ドット絵の確認の道具」）。依頼者には道具を通した完成品を見せる。

1. **物の見え方**: 兜・鎧・剣・盾を、単品で向きごと（down・up・left・right）に描いたページで合わせる
2. **重なり順**: 向きごとの層を奥→手前に並べたページで合わせる。合意した順が `checks/garum.json` の `orders` になる
3. **攻撃の動き**: 振り上げて叩きつける3コマを組み、再生ページで見せる
4. **完成品**: 道具を例外0件で通した全コマを、状態×4方向の再生ページで見せる。承認の後でゲームへ書き出してコミットする

見せ方はこれまでどおり Artifact のページ（スマホで見る）。赤枠の印を付けるときは印なしと対で並べる。
絵を変えたら、コミットや次の段階の前に見せる。

### 目標

- `pixel-asset-forge/compose/garum.json` と `checks/garum.json`、`sheets/garum.txt` を作り、全コマを単品の部品から組む
- `tools/unit_rules.py checks/garum.json` が例外0件（`exceptions: []`）で通り、`compose.py compose/garum.json --check` が通る
- ゲームの `assets/images/garum-map.png` を新しいシートに差し替え、`npm test`（`sheet-size.test.ts` を含む）が通り、ゲームで動く

## 目標にしないこと

- 顔グラ（`garum-face.png`）は変えない
- 攻撃のエフェクトの大きさ・位置の直し（上の「決めたこと」）
- ガルムの強さ・動き（`garum.json` の数値やコマ数）は変えない
- ほかのユニットの絵や、32px での道具の判定を変えない（新しい道具が要ると分かったら、作る前に依頼者と相談する）

## 決まっていて、守ること

- 正典: `pixel-asset-forge/types/unit/SPEC.md`（特に「部品で組む規約」「色の決まり」「描く手順」）、`pixel-asset-forge/CLAUDE.md`、ルートの `CLAUDE.md`
- 部品は単品として完全に描く。重ねた後の後処理で補わない
- 腕は描かない（体＋拳）。袖の名残も残さない
- 拳は全向き・全コマで両手とも層を持つ。体の奥で武器を握る拳は影の肌の色だけで描く（`far_fist_check`）。
  拳は種類 `skin` の色で塗る（Claude の判断）。鎧の騎士の敵（`dagger-knight`・`spear-knight`）も拳は `fist/enemy_male` の肌の色で、
  手の色を種類 `skin` から読む道具（`fist_check`・`far_fist_check`・`weapon_check`・`hand_outline`・`compose.py` の `hand`）も変えずに済む。
  籠手の色にしたいと依頼者が確認1で言ったら、道具の直しが要るので、その時点で作る前に相談する
- 拳の位置は down/up・left/right で左右反転にそろえる（攻撃のコマを除く。`hand_mirror`）。剣・盾は left/right で位置をそろえる（`weapon_mirror`）
- 剣の大きさは、48px の決まり（1.5倍した値）の中で描く（Claude の判断）。体が1.5倍なので、決まりの中でも画素の数ではロランの剣より長く太くなる。
  待機・歩きで切っ先が頭頂を越えない決まり（`blade_height`）はガルムにも当てはめ、例外にしない。
  攻撃の振り上げで剣が上に収まらなければ、頭の後ろへ寝かせるなどの形を確認3で見せて合わせる
- 剣と盾を持つ形はロランと同じ。持ち方・重なり順はロランの承認済みの順（`checks/roran.json` の `orders`）を手本にし、確認2で合わせる
- 承認された重なり順は Claude が勝手に変えない
- 新しい色は描く前に `probe_colors.py` で測り、用途の色は種類と説明を書いて `palette/uses/unit.json` に足す。
  兜は `headgear`、鎧は `cloth`、剣・盾は武器の部品の決まり（輪郭と刃・武器の種類だけで塗る）。剣・盾は武器専用の色を使う
- 背丈（36〜39px）は芯で測る（`height_check`）。兜は被り物の部品なので背丈に入らない
- シートの並びはほかのユニット（`sheets/roran.txt` など）にそろえる（12行 = 3状態 × 4方向）

## 作る人に任せること

- 第1段階の直し方（大きさを読む関数をどこに置くか、比率の値の端数の丸め方）。丸め方は SPEC に書く
- 芯を新しく描くか、32px の素体を拡大して下書きにするか
- 兜の角の飾り・鎧の形・剣と盾の大きさと形（確認1で依頼者に見せて合わせる）
- 目の部品（既存の E0〜E5 を使うか、新しく描くか）
- 赤と青の具体的な色（既存の色見本を優先し、足すなら測ってから）
- 計画の分け方（タスクの切り方。第1段階と第2段階を別の PR にすることは決まっている）
