# ミストのマップ用ユニット Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ミスト（黒基調のローブ・紫のつば広の帽子・茶色の長い髪・杖）の24コマを単品の部品から `compose/mist.json` で組み、`unit_rules.py` を例外0件で通して、ゲームの `mist-map.png` を差し替える。

**Architecture:** 絵はグリッド（`assets/part/**`）だけを描き、`tools/compose.py` で `assets/unit/mist/` のコマを組む。確認は `checks/mist.json` を `tools/unit_rules.py` にかける。シートは `sheets/mist.txt` を `tools/sheet.py`、ゲームへは `tools/export.py ../sprites.json ../assets/images`。依頼者に見せて止まるのは設計書の確認1〜4の4か所だけ。

**Tech Stack:** Python 3.14（forge の `.venv`）、unittest、forge の `compose.py`・`unit_rules.py`・`validate.py`・`probe_colors.py`・`check_colors.py`・`compose_page.py`・`phone_sheet.py`・`anim_compare.py`・`sheet.py`・`export.py`・`contact_sheet.py`。ゲームは Vite + Vitest（`npm test`・`npm run build`）。

**Spec:** `docs/superpowers/specs/2026-11-06-mist-unit-design.md`（character-tactics の直下）

コマンドは断りが無ければ `pixel-asset-forge/` で実行する。進捗台帳は `.superpowers/sdd/2026-11-06-mist-unit/progress.md`（character-tactics の直下）。ブランチは `feat/mist-unit`。

## Global Constraints

- 部品の置き場と名前（部品の名前はファイル名の `_<向き>_` より前。`unit_config.part_name`）。状態は `base`・`idle2`・`atk_wind`・`atk_hit`、歩きは `base` の部品を使う:
  - 芯: `assets/part/body/mist/core_<dir>_<状態>.txt`（歩きの `walk_a`・`walk_b` も芯は持つ）
  - 帽子: `assets/part/head/witch/head_witch_<dir>_base.txt`（種類 `headgear`）
  - 髪: `assets/part/hair/mist/hair_mist_<dir>_base.txt`（前）・必要なら `hair_mist_back_<dir>_base.txt`（肩より下・奥）
  - 目: 既存の `assets/part/eye/E*/` を使えれば使う。使えなければ `assets/part/eye/mist/eye_mist_<dir>_base.txt`
  - ローブ: `assets/part/cloth/robe/cloth_robe_<dir>_<状態>.txt`（1つの服の部品。設計書の Claude の判断）
  - 杖: `assets/part/equip/staff/staff_<dir>_<状態>.txt`（名前 `staff`。種類 `weapon` と輪郭だけで塗る。`blade` は書かない）
  - 杖を握る拳: `assets/part/fist/mist/staff_hand_<dir>_<状態>.txt`、空き手: `assets/part/fist/mist/free_hand_<dir>_<状態>.txt`
- 芯は `assets/part/body/enemy_female/core_*`（24ファイル）の複製から作り、肌を `skin_ruddy_*`→`skin_fair_*` に替える（Claude の判断: 体＋拳で道具を通った女性の芯があるため）。服の色の上はローブが覆う
- 歩き: ローブの裾は全コマで `base` のまま。足先は芯の y=28〜30 でのぞき、それだけが動く（設計書「歩きの見せ方」(a)）。裾の下端は y=27 以上に置く
- 待機2: 杖とそれを握る拳を `base` から y に −2 ずらす（ガウ・敵と同じ。Claude の判断）。`checks` の `moves: true` を付ける
- 色: 黒基調のローブ（既存 `clothes_dark_*` を優先）、紫の帽子、茶色の髪、金の留め金、杖。新しい色見本は描く前に `probe_colors.py` で、隣り合う予定の相手（輪郭・肌・ローブ・帽子）と測り、`swatches.json` と `palette/uses/unit.json`（種類と説明つき）に足す
- 正典の決まり（`types/unit/SPEC.md`）: 部品は単品として完全、腕と袖は描かない、拳は全向き・全コマ両手の層を持ち四方を輪郭で閉じる、体の奥で杖を握る拳は影の肌の色だけ、拳は down/up・left/right で左右反転（攻撃を除く）、杖は left/right で左右反転（攻撃も）、被り物は髪より大きく、柄を包んで握る物は拳を手前
- 魔法の弾・光は描かない
- 攻撃は3コマ（`atk_wind`・`atk_hit`・`base`。ゲームは最後のコマで弾を出す）。シートの並びは `sheets/roran.txt` と同じ
- 道具で落ちたら道具に従って絵を直す。道具の判定を変えない、例外（`exceptions`・`open_chars`）で通さない、新しい機械チェックを作らない（要ると分かったら作る前に依頼者に聞く）
- 承認された重なり順を Claude が変えない。絵を変えたら、コミットや次の段階の前に見せる
- 依頼者に見せるのは Artifact のページ（スマホで見る、PNG を data URI で埋め込む）。赤枠の印は印なしと対で並べる。動きは状態×4方向の再生ページ
- テストは `assets/` を読まない（`tests/test_no_live_assets.py`）。一時の出力は scratchpad。push・PR は依頼者の指示があったときだけ

## Review Focus

- **歩きが見えない**: 裾が足先を覆うと歩きのコマが立ちと同じに見える → Task 4 Step 3 で、歩きの各コマで芯の y=28〜30 の画素がローブに隠れずに base と違うことを確かめる
- **帽子と髪**: つば広の帽子の縁より下で髪が横にはみ出す → `head_cover_check` が Task 3・4 の `unit_rules` で落とす。背面を確認2のページで拡大
- **奥の拳の色**: left/right で体の奥の杖の拳が影の色でない（全状態） → `far_fist_check`（Task 4・5 の `unit_rules`）
- **長い杖と帽子・フレーム**: 掲げる案で杖の先が帽子と重なる・32px からはみ出す → Task 5 Step 2 の `validate.py`（行長）と確認3のページで `atk_hit` を拡大
- **書き出しの取り違え**: `sprites.json` に `sheets/mist.png` が無い・名前違いでゲームが古い絵のまま → Task 6 Step 5 で `mist-map.png` が 128x384 で、仮の絵と画素が違うことを確かめる
