# 敵ユニットのパーツ差し替え 計画（2026-10-06・親計画 2026-10-06-enemy-variants.md の方針変更）

親計画（色替えと男女）のまま作ると、敵がすべてガウに見える。依頼者と合意した変更:
**ガウの男性素体を土台に、頭・目・服・武器を部品として差し替える。** 色替え（T1〜T5 の仕組み）は、部品の上に重ねる色の層として残す。

## 親計画との違い

- T6〜T9（女性素体・ゲームへの書き出し）は止める。部品で十分に離れるかを見てから決める
- 完成コマの色替えだけでなく、「ガウの素体 + 部品」で組んだコマを敵のコマ一式として作る
- ガウの完成コマは手仕上げ込みなので組み直しと一致しない（差は約110〜170画素/コマ）。差の大半は色
  （素体の `cloth_*`/`skin_*` が `cloak_dark_*`/`skin_rose_*`、脚が `wood_shadow`）で、形の差は攻撃コマの輪郭など数画素

## 段階

1. **CP-A（確認ポイント）**: 立ち（base）4方向で、頭4種・目5種・服の変化3種を選ぶページ（`tools/unit_picker.py`）で見せる。依頼者が「ガウに見えない」かを判断する。**ここで止まる**
2. CP-A 承認後、採用した部品を待機・歩き・攻撃のコマへ広げる（頭は立ちと共通の帯。歩きは脚だけ違う）
3. 武器（斧・槍）と半袖は CP-A の結果を見てから別に決める。斧・槍は4方向の立ちと攻撃（振りかぶり・当たり）の約12コマを新しく描く
4. 全体を1回レビューする。push と PR は依頼者の指示があったときだけ

## 守ること

親計画と同じ（確認ポイントで実際に止まる／絵を変えたら `tools/validate.py` を通してから見せる／unittest／コミットは Conventional Commits + 日本語）。
