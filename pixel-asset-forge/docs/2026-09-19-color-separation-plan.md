## テストで固定すること

1. **Lab 変換が既知の値と一致する** — 黒 L*=0、白 L*=100
2. **明度エッジの2軸** — 絶対差と比のそれぞれで合格すること
3. **役割で floor が変わる** — `outline` を含むペアだけ厳しい
4. **同一色は隣接ペアにならない** — これが「消えた目地」を拾えない理由なので、
   仕様として固定する
5. **背景セルは対象外**
6. **収束済みの `chest` / `plain` が無警告** — しきい値の回帰。ここが将来鳴り出したら
   しきい値かパレットが変わったということ
7. **`knight` が `outline`/`pupil` で hard failure** — 既知の未解決を固定する。
   パレットを直したらこのテストも直す

## やらないこと

- `pupil` の色を決めて `knight` を直すこと。未確定項目（マスターパレットの具体的な色）
  に当たるため、依頼者の判断を待つ
- `validate.py` への統合。構造の hard gate と絵の助言は分けたまま
- マルチタイル（2x2の城）を繋げて確認するツール。別件として残す
