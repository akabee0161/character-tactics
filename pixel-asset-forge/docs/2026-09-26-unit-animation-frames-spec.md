# `unit` ロランの `base` 以外の20コマを新しい立ち絵に揃える（仕様）

作成: 2026-09-26。**このファイルは作成時点のログ**。運用の最新は `README.md` と `CLAUDE.md` と
`types/unit/SPEC.md` を見ること。

## 背景

2026-09-26 に PR #4 でロランの立ち絵4枚（`{down,up,left,right}_base`）を新しい規約で描き直した
（右手に剣・左手に盾、剣は立てて構える、奥の物は体に重なる部分を隠す、横顔は平ら。規約は
`types/unit/SPEC.md` の「立ち絵4方向の規約」）。

残りの20コマ（4方向 × `breathe` / `walk_a` / `walk_b` / `atk_wind` / `atk_hit`）は旧い絵のままで、
剣を下げて持っている。`idle` は `[base, breathe]`、`walk` は `[base, walk_a, base, walk_b]`、
`attack` は `[atk_wind, atk_hit, base]` なので、シート上では新旧の絵が交互に出て、剣が上下に飛ぶ。
また `right_*` の5コマは `left_*` の `mirror_x` 派生のままで、光源と装備の前後が反転している
（`ISSUES.md` の2行）。

## 目的と終わった状態

- 20コマを立ち絵の規約に揃え、`base` と交互に出ても絵が飛ばない状態にする
- `right_*` 5コマを本体グリッドにする
- **終わった状態:** `tools/sheet.py sheets/roran.txt` のプレビューで、4方向 × 3状態のアニメが
  新しい `base` と一続きに見える。各状態の4方向を依頼者が目視で承認している

## 前提（変えないもの）

- コマ構成（`idle` 2 / `walk` 4 / `attack` 3、中間と戻りは `base` の流用）と `sheets/roran.txt` は変えない
- 立ち絵4枚（`*_base`）と素体（`types/unit/base/`）には触らない
- 解像度・構図（足元 y=30、左右中央、背丈26px）、パレット、光源 upper-left は変えない
- ゲーム内での確認はしない。縮小表示での見え方は考慮しない（前回と同じ依頼者の指定）
- 新しい機械チェックもツールの変更もしない

## 決めたこと

### 1. 作り方: 20コマとも全身グリッドを手で描く

`docs/HANDOFF.md` 2.4 は「複数フレームはコード側の決定的変形で作る」としている。
`docs/2026-09-23-findings.md` では `breathe` が純粋な行シフトだった。しかし剣を立てて構えた今は、
頭と同じ行に刃があるので、行シフトでは刃も1px縮む。行と列の範囲を指定する部分変形
（`shift_band` の拡張）をツールに足せば `breathe` 4コマは派生にできるが、それで減るのは4コマだけで、
`walk` と `attack` は結局手で描く。今回は採らない（依頼者の選択）。

行シフトは描くときのその場限りのスクリプトで下書きしてよい。コミットするのは手で仕上げたグリッドだけ。

**既知のリスク:** 依頼者は頭身を後で調整する可能性がある（`ISSUES.md` の素体の項目）。
そのときは24コマとも描き直しになる。部分変形の追加はその時点で改めて検討する。

### 2. 共通の規約

- 立ち絵の規約をすべて引き継ぐ: 右手に剣・左手に盾、4方向の手前／奥の表、奥の物は体に重なる部分を隠す、
  色は手前も奥も同じ、横顔は平らで目は1px、顔の内部に目以外の `outline` を使わない、光源 upper-left
- **`right_*` も本体グリッドにする。** `left_*` を反転して描き始めない
- **盾はどのコマでも `base` の位置から動かさない。** 動かすのは剣を持つ腕と脚だけ。コマ間のずれを最小にするため
- 足元は y=30。`atk_*` 以外は中心 15.5±1・背丈26

### 3. 各状態の動き

**`breathe`（`idle` の2コマ目）**
- 頭を1px下げ、首を1行潰す（前回と同じ動き）
- 剣は拳ごと `base` の位置に固定し、刃を縮めない。頭と重なって隠れる部分だけが変わる

**`walk_a` / `walk_b`**
- 上半身と剣は `base` のまま。脚だけを動かす
- 脚の形は旧 `walk_a` / `walk_b` の脚を新しい `base` に移す
- 横向きの脚は、手前を `cloth_base`、奥を `cloth_shadow` で塗る

**`atk_wind`（振りかぶり）**
- 攻撃の動きは**振り下ろし**（依頼者の選択。突き・横薙ぎは採らない）
- 剣を持つ拳を頭の高さまで上げ、刃を真上に立てる。**攻撃コマに限り、切っ先は頭頂（y=5）より上に出てよい**
  （依頼者の選択。コマの上端 y=0 まで使える）。立ち絵の「頭頂より上に出さない」は構えについての規約として残す
- 横向きでは拳を頭の後ろ側に引く

**`atk_hit`（振り下ろし）**
- 拳を体の前の胸〜腰の高さに下ろし、刃を前下がりの斜めに振り切った姿勢にする
- 横向きでは進行方向へ斜めに下ろす
- `down` では体の前を斜めに横切り、胴に重ねて描く
- `up` では剣が体の向こうに行くので、体に重ならない切っ先側だけが見える
- 中心がずれるのは許容する（`sheet.py` の `off` 表示は仕様どおり）

**懸念:** `up` の `atk_hit` は剣の大半が体に隠れ、攻撃に見えにくい可能性がある。
描いてみて見えにくければ、ゲートで依頼者に相談する（隠す規約を崩すかどうかは依頼者が決める）。

### 4. 進め方と確認ゲート

状態ごとに4方向をまとめて描き、状態ごとに依頼者のゲートを置く。同じ動きが4方向で揃っているかを並べて見るため。

1. `breathe` 4コマ → ゲート
2. `walk_a` / `walk_b` 8コマ → ゲート
3. `atk_wind` 4コマ → ゲート
4. `atk_hit` 4コマ → ゲート

攻撃は動きの判断が最も多いので、振りかぶりと振り下ろしでゲートを分ける。

**各コマの機械的な確認（その場限りのコマンドで行う）:**
- `validate.py` が ok
- 足元 y=30。`atk_*` 以外は中心 15.5±1・背丈26
- `right_*` に `# from:` が無い

**目視:**
- 各ゲートで、4方向の `base` と対象コマを並べた画像を依頼者に見せる
  （`contact_sheet.py` にファイルを渡す。並びはファイル名順になる）
- 最後に `sheet.py sheets/roran.txt` のプレビューで、足元の赤線と `base` との並びを確認する
