# item 型

持ち物・小物の単体アセット。[character-tactics](https://github.com/akabee0161/character-tactics) では
役割アイコン（16px で描き 32px＝2倍で表示）と、ユニットの持ち物を描くときの元絵を兼ねる。
以下は `chest`・`sword`・`bow` の3点で実測した規約（issue #23 の3番目、2026-10-02）。

`reference/` はまだ無い。手本は `assets/item/` の3点。

## 確定している規約

| 項目 | 値 |
|---|---|
| 解像度 | 16x16 |
| 背景 | `bg: transparent` |
| 光源 | `# light: upper-left`（タイル・ユニットと同じ） |
| 輪郭 | `outline` を全周1px。輪郭以外の画素の上下左右に透明を置かない（3点とも穴なし） |
| 余白 | 外接矩形は x・y とも 1〜14（輪郭込み。3点とも同じ） |
| 大きさ | 16px いっぱいに大きく描く。ユニットの持ち物の画素の大きさ（ロランの刃2px幅）には合わせない |
| 色 | `palette/master.json` の既存色。素材ごとの割り当ては下の表 |

素材ごとの色の割り当て:

| 素材 | 色 | 使っているアセット |
|---|---|---|
| 刃・鏃・弦（白銀の金属） | `stone_hi` / `stone_base` / `stone_shadow` | `sword`・`bow` |
| 木（鍔・柄・弓本体・矢の軸・箱） | `wood_hi` / `wood_base` / `wood_shadow` | 3点 |
| 木の最も暗い面 | `wood_dark` | `chest` のみ |
| 金具（金色の金属） | `metal_hi` / `metal_base` / `metal_shadow` | `chest` |
| 宝石（赤） | `roof_hi` / `roof_base` / `roof_shadow` | `sword` の柄頭 |
| 羽根（青） | `water_hi` / `water_base` / `water_shadow` | `bow` の矢羽根 |

この割り当ては設計時に依頼者が決めた（ロランのユニットの剣の刃も `stone_*`）。
`ISSUES.md` の「剣が `stone_*`、盾が `metal_*` で命名と見た目が合っていない」は残っている（ユニット側の整理は issue #23 の4番目以降）。

実測した色数: `chest` 8、`sword` 10、`bow` 10（`outline` を含む）。

## 長い持ち物（剣・弓）の規約

- **向き:** 右上に先端を向けた45°の斜め置き。軸は線 `(x, 15-x)` で、`x = 2..13` の画素をすべて不透明にする
  （左下 `(2,13)` が柄頭・矢の尾、右上 `(13,2)` が切っ先・鏃の先）
- **形は軸について左右対称にする。** 軸 `x+y=15` で折り返して形（不透明な画素）が重なること。
  色は光源に従うので対称にしない（左上側を `*_hi`、右下側を `*_shadow`）。
  斜めに偶数列の太さの部品（例: 刃を2列）は中心線が画素の境目に来て対称にならないので、奇数列にする（剣の刃は3列）。
  ここでの「列」は軸に平行な斜めの線（`x+y` が一定の線）の本数
- **軸の上だけにある1列の細い部品は1色で塗る。** 左上・右下の側が無いので明暗を付けない
  （剣の握り・矢の軸はどちらも `wood_shadow`）
- **尖った先端を、輪郭に囲まれた1画素で表さない。** 先端の画素の上下左右をすべて輪郭にして、本体と斜めの角だけでつなげる形にしない
  （弓の鏃の案で、依頼者が「先端の1pxの白と周りの黒で表現した部分はいらない」と判断した。剣にも当てはめて描き直し、規約として有効と判断された。2026-10-02）。
  - 先端は、部品の最後の段の2画素と、その間の角の1画素の計3画素で作る。角の画素は、上下左右のうち2方向で本体とつながる。
    `sword` は `(12,2)`・`(13,2)`・`(13,3)`、`bow` の鏃も同じ位置の3画素
  - 1画素を除いたぶん、部品を先端の向きへ1段（右上へ1px）伸ばす。長さを保ち、軸の `(13,2)` を不透明のままにするため
  - 先端の角の画素は、軸の上なので部品の中間の色にする（剣・鏃とも `stone_base`）。左上の画素は `*_hi`、右下の画素は `*_shadow`
- **剣:** 柄頭→握り→鍔→刃を1本の軸に並べ、鍔は刃に直角にする（`types/unit/SPEC.md` の攻撃の規約と同じ）。
  `sword` は刃3列・握り1列（両側を輪郭で囲む）・柄頭に 2x2 の宝石。
  鍔は軸に直角な階段状の並び（`x-y` が -3 と -4 の2本の線が交互になる）で、軸の画素 `(6,9)` の左右に4画素ずつ、計9画素
- **弓:** 矢は剣と同じ軸に対角線いっぱいに置く。弓はもう一つの対角線に置き（`bow` は両端が `(2,2)` と `(13,13)`）、
  弧は鏃の側へ膨らませる。弧の頂点は鏃ではなく矢の木の部分と交わる（鏃に重ねない）。
  弦は弓の両端を結ぶ直線で、矢と真ん中で交わる。矢羽根は弦の外側（左下）に置く

## 未確定（勝手に決めない）

- **アセットあたりの色数上限** — 未定（`# max_colors:` は書かない）。実測は上のとおり
- **`reference/` に何を置くか** — 未定。今は `assets/item/` の3点が手本
- **宝箱など、長くない小物の向き** — `chest` は正面向き。斜め置きの規約は長い持ち物にだけ当てはめている
- **弦の描き方** — `bow` の弦は全周輪郭の規約に従って輪郭で囲んだので、斜め3列の太さになる（手本の `role-yumi.png` は輪郭なしの1画素）

## 経緯

設計は character-tactics の `docs/superpowers/specs/2026-10-02-item-icons-sword-bow-design.md`（作成時点のログ）。

- 手本はゲームの役割アイコン `assets/images/role-tate.png`（剣）・`role-yumi.png`（弓）の**構図だけ**を取った。
  どちらも 32px で、色が master パレットの外なので、色と画素は写していない
- 剣は計画の3案（刃3列・刃2列で長い・溝あり）から、依頼者が「刃2列で長い案の長さ」と「刃3列の案の鍔」を組み合わせ、
  左右の非対称を指摘して刃を3列にした
- 弓は、矢を対角線いっぱいに置いてもう一つの対角線の弓と交差させる配置を依頼者が指示した。
  鏃が弓に重なっていた案から、鏃の先端1画素を除いて右上へ1px ずらし、矢の木の部分を伸ばした
- この鏃の直しを規約にし（「尖った先端を、輪郭に囲まれた1画素で表さない」）、剣の切っ先にも当てはめて描き直した。
  先端の1画素を除くだけの案（刃が1段短くなる）と比べ、刃を1段伸ばす案を依頼者が選んだ
