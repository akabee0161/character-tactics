# face 型

顔グラフィック。絵柄は本文ではなく `reference/` で揃えること。
以下は機械的な規約のみを書く。

## 確定している規約

| 項目 | 値 |
|---|---|
| 寸法 | `32x32`（`reference/knight.txt` で実用水準に到達した数字） |
| 光源 | 左上固定（`# light: upper-left`） |
| 背景 | 縦グラデーション `gradient:#1c1834->#323256`。透過にしない |
| 輪郭 | `outline` を全周に1pxで回す |

## 構成要素

reference が満たしている要素。新規の顔グラもこれを満たすこと。

- **肌**: `skin_hi` / `skin_base` / `skin_shadow` / `skin_deep` の4段。頬と顎下に影を置く
- **髪**: `hair_hi` / `hair_base` / `hair_shadow` / `hair_dark` の4段。左上が明るく右下へ落ちる
- **目**: `eye_white` / `iris` / `pupil` の3要素を横3pxで構成する
- **口**: `mouth`
- **衣服**: `cloth_hi` / `cloth_base` / `cloth_shadow` の3段

## 未確定（勝手に決めない）

- **アセットあたりの色数上限** — 未定。reference は14色（パレット定義は16エントリ）。
  実測が溜まるまで `# max_colors:` は書かない
- **目指す絵柄** — 「SFC世代相当の作り込み」以上の指定はない。
  レトロ機の制約（16色縛り等）を再現する意図はない
- **顔グラをドット絵で通すかどうか** — 通常の CG 絵に切り替える選択肢が残っている

## reference の既知の弱点

`reference/knight` は合格例だが完成ではない。以下は次の改善対象であって、
真似すべき特徴ではない。

- 髪がヘルメット状で毛束・流れがない
- 眉と上まつげが分離せず黒い横棒になっている
- 顔の輪郭が長方形で頭蓋の丸みがない
- 首が太く肩との境界が不明瞭
