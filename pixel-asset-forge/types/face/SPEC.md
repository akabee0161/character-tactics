# face 型

顔グラフィック。絵柄は本文ではなく `reference/` で揃えること。
以下は機械的な規約のみを書く。

手本は `reference/roran`（64x64）。`reference/knight` は旧規約（32x32）の手本で、あとで見比べられるように残している（新しい顔の寸法や色の名前は roran に揃える）。

## 確定している規約

| 項目 | 値 |
|---|---|
| 寸法 | `64x64`（ゲームの README の「アセットの大きさの規約」） |
| 光源 | 左上固定（`# light: upper-left`） |
| 背景 | 透明（`# bg: transparent`）。ゲームのほかの顔にそろえる（2026-09-30 依頼者） |
| 輪郭 | `outline` を全周に1pxで回す |

## 構成要素

`reference/roran` が満たしている要素。新規の顔グラもこれを満たすこと。
色のキーはキャラクターごとに足す（roran は `*_slate` / `*_rose` / `cloak_dark_*`）。

- **肌**: `hi` / `base` / `shadow` / `deep` の4段（roran は `skin_rose_*`）。前髪の下、頬の外側、耳、首に影を置く
- **髪**: `hi` / `base` / `shadow` / `dark` の4段（roran は `hair_slate_*`）。分け目から伸びる房ごとに、光の側の縁を明るく、反対の縁を暗くする
- **眉**: 髪の一番暗い色。目頭から目じりまでの幅で、上まぶたとの間に肌を1行空ける
- **目**: 上まぶた（`outline`、目じり側を太く）、瞳（暗い色と明るい色の2色。roran は `iris_slate_dark` / `iris_slate`）、光1点と目頭・目じりの白（`eye_white`）。両目の瞳は同じ向きに寄せる（寄り目にしない）
- **鼻**: `outline` の垂直に近い線で鼻筋を下ろし、鼻先で短く折り返して閉じる。鼻の穴は描かない
- **口**: 閉じた線。黒い部分の両端を肌の一番暗い色にしてやわらげる
- **衣服**: `hi` / `base` / `shadow` の3段（roran は `cloak_dark_*`。上の縁だけを明るく光らせたマント）

## 未確定（勝手に決めない）

- **アセットあたりの色数上限** — 未定。roran は15色、knight は14色。
  実測が溜まるまで `# max_colors:` は書かない
- **目指す絵柄** — 「SFC世代相当の作り込み」以上の指定はない。
  レトロ機の制約（16色縛り等）を再現する意図はない
- **顔グラをドット絵で通すかどうか** — 通常の CG 絵に切り替える選択肢が残っている
- **部品とパラメタから顔を作る工程** — `ISSUES.md` の「顔グラを部品とパラメタから作る工程」

## reference の既知の弱点

`reference/roran` は合格例だが完成ではない（`ISSUES.md` の「ロランの顔にまだ磨く余地がある」）。以下は次の改善対象であって、真似すべき特徴ではない。

- 髪の房が分け目から扇状に規則正しく並び、大小の房の重なりが無い
- 頬骨・目のくぼみの立体が弱い
- 服は元絵の首元を真似たマントのままで、服のパターンが無い
